# Demo Paper 系统设计风格说明

## 1. 设计定位

本系统不是通用聊天产品，也不是心理咨询宣传页，而是面向 `CCF-B 论文 demo / 系统演示 / 答辩汇报` 的研究型交互系统。

因此，整体视觉定位应当是：

- `科研感`：白底、灰线、低饱和蓝色，强调理性、可信、专业
- `系统感`：模块关系清楚，结构稳定，避免花哨装饰
- `证据感`：回答、量表、图谱、证据链都应当像“可追溯研究结果”
- `风险感`：自杀风险检测语境下，界面要克制，不娱乐化，不做情绪化营销风

## 2. 视觉关键词

- 白灰蓝
- 低饱和
- 高留白
- 细边框
- 轻阴影
- 强结构
- 论文演示系统

## 3. 我们自己的设计点

参考图提供的是外部气质，但本系统必须保留自己的识别性。核心设计点如下：

### 3.1 风险检测工作台

智能问答页不是普通对话页，而是：

- 中间：`问答与推理输出`
- 右侧：`知识清单 / 图谱 / 证据依据 / 深入理解`
- 底部：`模式切换 / 追问入口 / 输入工作区`

这体现的是“研究辅助推理台”，不是社交聊天界面。

### 3.2 风险等级与证据透明

系统围绕“自杀风险检测”展开，设计上必须强化：

- 风险等级
- 证据链
- 图谱关系
- 量表支撑
- 干预与转介建议

因此蓝色用于主交互，绿色用于稳定/完成，黄色用于预警，红色仅保留给高风险告警。

### 3.3 论文演示友好

界面要方便在论文 demo、答辩录屏、导师汇报中展示，因此要做到：

- 主信息一眼能看清
- 大块留白，避免页面噪音
- 侧栏和工作台位置固定，便于讲解
- 卡片层级清楚，适合逐模块说明

## 4. 配色系统

### 主色

- 主蓝：`#2F6BFF`
- 深蓝：`#1D4ED8`
- 浅蓝背景：`#EEF5FD`

### 中性色

- 页面底色：`#F6F8FB`
- 卡片底色：`#FFFFFF`
- 分割线：`#E2E8F0`
- 主文字：`#162033`
- 次文字：`#516276`

### 语义色

- 成功 / 正常：`#1F9D72`
- 预警：`#F59E0B`
- 高风险 / 错误：`#DC2626`

## 5. 组件策略

### 左侧导航

- 白色或极浅灰底
- 当前项使用浅蓝底 + 蓝色图标 + 左侧细高亮条
- 不使用暖色大面积渐变

### 顶部栏

- 半透明白底
- 轻模糊
- 面包屑信息尽量简洁

### 内容卡片

- 优先使用白卡 + 灰边
- 阴影只做轻微悬浮感
- 大圆角保留，但控制在研究系统可接受范围

### 聊天输入区

- 大面积白卡
- 主要按钮用主蓝
- 模式标签用浅蓝底，不用高饱和强调色

### 知识清单 / 图谱

- 作为“研究知识工作台”存在
- 图谱背景浅蓝灰
- 节点低饱和配色
- 表格、前置知识、相关学习、深入理解要更像研究目录而不是资讯推荐

## 6. 不应出现的风格

- 大面积暖橙、米黄、治愈系宣传风
- 过多情绪化插画和装饰
- 营销感 hero 文案
- 娱乐化按钮和夸张发光
- 与自杀风险检测语境不符的轻松化表达

## 7. 最终目标

最终界面应让老师或评审一眼感受到：

- 这是一个认真做“自杀风险检测与干预辅助”的研究系统
- 不是简单聊天壳子
- 不是照搬外部页面
- 而是有自身任务语境、结构逻辑和论文演示目标的系统设计
