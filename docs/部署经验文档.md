# VIS4SRD 服务器部署经验文档

> 本文档记录 VIS4SRD（心理健康服务可视化系统）在服务器上成功部署的完整经验，涵盖架构设计、配置文件、容器编排、数据库初始化和运维命令。

---

## 一、项目概览

**VIS4SRD** (Visual Interactive System with Sentiment Analysis for Suicide Risk Detection) 是一个面向医生的心理健康服务系统，采用前后端分离架构，容器化一键部署。

- **部署形态**：Docker 容器化，docker-compose 一键启动
- **服务器访问**：无需登录到每台机器，直接通过 Docker 网络内部通信
- **自动化程度**：数据库初始化、种子数据导入、幂等更新全部自动化

## 四、Nginx 配置文件

### 4.1 生产 Nginx 配置 (nginx.server.conf)

文件位置: `frontend/nginx.server.conf` -- Docker 容器内使用

```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    # SPA 所有路由回退到 index.html
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理到后端（解决跨域）
    # 使用 Docker 内部 DNS（vis4srd-backend 是后端容器名）
    location /api/ {
        proxy_pass http://vis4srd-backend:3000/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 支持后端流式响应（SSE / ChatGPT 风格流式输出）
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }

    # 文件上传代理
    location /uploads/ {
        proxy_pass http://vis4srd-backend:3000/uploads/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 300s;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # 禁止访问隐藏文件
    location ~ /\. {
        deny all;
        access_log off;
        log_not_found off;
    }

    # gzip 压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1000;
    gzip_types text/plain text/css application/json application/javascript
               text/xml application/xml application/xml+rss text/javascript;
}
```

from contextlib import asynccontextmanager
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import JSONResponse
import orjson

class ORJSONResponse(JSONResponse):
    """自定义 ORJSONResponse，确保不转义 Unicode 字符（解决中文显示问题）"""
    def render(self, content) -> bytes:
        return orjson.dumps(
            content,
            default=lambda x: str(x),
            option=orjson.OPT_NON_STR_KEYS | orjson.OPT_SERIALIZE_NUMPY
        )

from src.core import init_pools, close_pools
from src.core.database import get_mysql_pool, get_pg_pool
from src.services import (
    DatasetService, UserService, MapService, ModelService,
    KnowledgeService, ChatService, ScaleService, HomeService

    health_router, dataset_router, user_router, map_router,
    home_router, system_router, scales_router, risk_router,
    knowledge_router, chat_router, models_router, demo_router
)

@asynccontextmanager
async def lifespan(app: FastAPI):

### 5.3 database.py (连接池管理)

文件位置: `backend/src/core/database.py`

```python
import asyncpg
import aiomysql
from .config import settings

_pg_pool = None
_mysql_pool = None

async def init_pools():
    global _pg_pool, _mysql_pool
    _pg_pool = await asyncpg.create_pool(
        host=settings.PG_HOST, port=settings.PG_PORT,
        database=settings.PG_NAME, user=settings.PG_USER,
        password=settings.PG_PASSWORD,
        min_size=settings.PG_POOL_MIN, max_size=settings.PG_POOL_MAX,
        server_settings={"client_encoding": "UTF8", "timezone": "Asia/Shanghai"},
    )
    _mysql_pool = await aiomysql.create_pool(
        host=settings.DB_HOST, port=settings.DB_PORT,
        user=settings.DB_USER, password=settings.DB_PASSWORD,
        db=settings.DB_NAME,
        minsize=settings.MYSQL_POOL_MIN, maxsize=settings.MYSQL_POOL_MAX,
        autocommit=True,
        init_command="SET NAMES utf8mb4",
        use_unicode=True, charset='utf8mb4',
    )
    return _pg_pool, _mysql_pool

async def close_pools():
    global _pg_pool, _mysql_pool
    if _pg_pool: await _pg_pool.close(); _pg_pool = None
    if _mysql_pool: _mysql_pool.close(); _mysql_pool = None

def get_pg_pool(): return _pg_pool
def get_mysql_pool(): return _mysql_pool
```

## 六、entrypoint.sh (智能初始化脚本)

文件位置: `backend/entrypoint.sh`

这是最关键的部署自动化脚本，实现**幂等初始化**：

```bash
#!/bin/bash
set -e

# 脚本目录检测（兼容两种 Dockerfile 布局）
if [ -d "/app/scripts" ]; then
    SCRIPTS_DIR="/app/scripts"
elif [ -d "/app/src/scripts" ]; then
    SCRIPTS_DIR="/app/src/scripts"
fi

INIT_LOCK="/app/.init_locks/.init_done"
VERSION_LOCK="/app/.init_locks/.init_version"

# 等待数据库就绪
wait_for_mysql() { ... }
wait_for_postgres() { ... }
wait_for_mysql_tables() { ... }

# 计算初始化脚本版本指纹（基于 MD5）
compute_version_fingerprint() {
    local scripts="seed_data.py seed_demo_data.py ..."
    for script in $scripts; do
        fingerprint="${fingerprint}$(md5sum "$SCRIPTS_DIR/$script" 2>/dev/null | cut -d' ' -f1)"
    done
    echo "$fingerprint" | md5sum | cut -d' ' -f1
}

# 决定是否需要重新初始化
should_initialize() {
    # 情况1：无锁文件 -> 需要初始化
    # 情况2：旧格式锁文件 -> 需要初始化
    # 情况3：代码版本变化 -> 需要重新初始化
    # 情况4：数据完整性检查失败 -> 需要重新初始化
    # 情况5：一切正常 -> 跳过初始化
}

# 主流程
if should_initialize; then
    # MySQL 初始化
    run_mysql_script "$SCRIPTS_DIR/sql/01_init_mysql.sql" "MySQL 表结构"
    run_python_script "$SCRIPTS_DIR/migrate_static_data.py"
    run_python_script "$SCRIPTS_DIR/seed_data.py"
    run_python_script "$SCRIPTS_DIR/seed_demo_data.py"
    run_python_script "$SCRIPTS_DIR/update_homepage_stats.py"

    # PostgreSQL 初始化
    run_python_script "$SCRIPTS_DIR/import_institutions.py"
    run_python_script "$SCRIPTS_DIR/import_hotlines.py"

    # 写入双重锁文件
    echo "$(date)" > "$INIT_LOCK"
    echo "$version_fingerprint" > "$VERSION_LOCK"
fi

# 启动 FastAPI
cd /app && exec uvicorn src.app:app --host 0.0.0.0 --port 3000
```

## 十二、部署架构总结

| 维度 | 设计选择 | 理由 |
|------|---------|------|
| **前端构建** | Vite 多阶段构建 + Nginx | 静态资源缓存，SPA 路由 fallback |
| **API 代理** | Nginx 转发 `/api/*` 到后端容器 | 避免 CORS，无需前端配置服务器 IP |
| **生产环境 API** | `VITE_API_BASE=` 空字符串 | 使用相对路径，Nginx 自动代理 |
| **数据库初始化** | entrypoint.sh 幂等脚本 | 代码版本变化自动重新初始化 |
| **数据持久化** | Docker volume | mysql_data, postgres_data, backend_init_lock |
| **健康检查** | 后端 curl health API | 确保前端只在后端就绪后才启动 |
| **PostgreSQL** | postgis/postgis:15-3.3 | 支持 PostGIS 空间查询（附近机构） |
| **字符编码** | utf8mb4 (MySQL) + UTF8 (PG) | 确保中文全文检索正常 |
| **镜像源** | 腾讯云 Debian 归档源 | 解决 Debian trixie 兼容性问题 |
| **pip 源** | 清华镜像 | 加速国内服务器依赖安装 |
