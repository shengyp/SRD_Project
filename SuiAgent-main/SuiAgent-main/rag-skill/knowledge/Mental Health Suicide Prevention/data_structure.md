# 领域目录索引：Mental Health - Suicide Prevention

本目录包含青少年与成人自杀风险筛查、评估流程、预防干预措施及临床处置路径，用于自杀风险识别与危机防控参考。

- NIMH_ASQ_青少年门诊临床路径.pdf
  - 用途：提供 8-24 岁青少年门诊自杀风险阳性后的简短安全评估流程与处置方案。
- NIMH_ASQ_住院临床路径.pdf
  - 用途：规范儿科住院患者自杀风险三级筛查流程、阳性患者安全防护与转诊处置标准。
- NIMH_ASQ_成人急诊临床路径.pdf
  - 用途：指导成人急诊自杀风险阳性患者的快速评估、风险分级与紧急精神科干预流程。
- NIMH_5行动步骤.pdf
  - 用途：总结大众可执行的 5 步自杀干预法，用于帮助有自杀想法人群的基础实操指南。
- CDC_青年自杀预防机会_PDF.pdf
  - 用途：分析美国青年自杀流行特征、风险因素，提出公共卫生层面的预防策略与临床干预机会。
- WHO：预防自杀——心理辅导员手册 (权威中文版).pdf
  - 用途：世界卫生组织权威指导手册，面向心理辅导员提供自杀预防理论、风险评估、危机干预、特殊人群辅导、社区宣教及幸存者支持全流程专业方法。
