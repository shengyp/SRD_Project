# 领域目录索引：Mental Health - Mental Disorders

本目录包含各类常见精神心理疾病的基础科普、症状识别、诊断标准与治疗方案，用于快速查询儿童、青少年及成人常见心理障碍的专业知识。

- NIMH_青少年抑郁.pdf
  - 用途：介绍青少年抑郁的核心症状、自我判断方法与求助途径，面向青少年群体科普抑郁相关知识。
- NIMH_双相障碍.pdf
  - 用途：系统说明双相情感障碍的分型、症状表现、诊断依据、药物与心理治疗方案及日常管理方法。
- NIMH_ADHD 基础.pdf
  - 用途：讲解注意缺陷多动障碍的症状分型、病因、诊断标准、主流治疗方式与家庭 / 学校干预策略。
- NIMH_自闭谱系障碍.pdf
  - 用途：阐述自闭症谱系障碍的核心特征、不同年龄段表现、诊断流程、干预服务与家庭支持方法。
- NIMH_进食障碍.pdf
  - 用途：介绍神经性厌食、贪食、暴食等常见进食障碍的症状、危害、治疗方案与共病心理问题干预。
- NIMH_PTSD.pdf
  - 用途：说明创伤后应激障碍的发病原因、症状分类、诊断标准、心理治疗与药物治疗规范。
- NIMH_季节性情感障碍.pdf
  - 用途：科普季节性情感障碍的发病规律、冬 / 夏季型症状差异、光疗、药物等治疗手段。
- NIMH_破坏性心境失调障碍.pdf
  - 用途：讲解儿童青少年破坏性心境失调障碍的诊断标准、症状表现、行为干预与药物治疗方案。
- NIMH_儿童与心理健康.pdf
  - 用途：指导家长识别儿童心理异常信号、评估流程、治疗选择及家校协同支持方法。
