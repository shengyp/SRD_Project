## 二、热线使用场景说明

### 2.1 什么情况适合拨打热线？

| 场景 | 说明 | 推荐热线 |
|------|------|---------|
| **有自杀想法但还未采取行动** | 感到绝望、有轻生念头时 | 任意热线（首选 12356 / 400-821-1215） |
| **刚刚经历重大丧失** | 亲人去世、关系破裂等 | 任意热线 |
| **严重心理创伤** | 暴力、灾难、事故等应激事件后 | 任意热线 |
| **突发精神症状** | 极度恐惧、幻觉、无法控制情绪 | 热线 + 尽快就医 |
| **物质滥用问题** | 酒精、药物成瘾困扰 | 任意热线（可转介成瘾科） |
| **家庭/亲密关系危机** | 争吵激烈、濒临分手等 | 任意热线 |
| **长期情绪困扰** | 抑郁、焦虑等慢性情绪问题 | 任意热线（可转介长期心理服务） |
| **为他人担心** | 家人/朋友有自杀风险 | 任意热线（可获得指导） |
| **只是想找人倾诉** | 感到孤独、无人可说 | 任意热线 |

### 2.2 热线不适用的情况

| 情况 | 建议 | 热线能力范围外 |
|------|------|--------------|
| **精神药物调整** | 需就诊精神科/心理科 | 热线接线员不能调药 |
| **精神科急诊** | 严重自杀行为、药物过量 | 立即拨打 120/110 |
| **诊断评估** | 需要详细精神科诊断 | 需面诊 |
| **长期心理治疗** | 系统性心理咨询 | 热线转介至咨询师/治疗师 |
| **法律纠纷** | 需法律援助 | 拨打法律服务热线 12348 |

## 三、热线咨询流程

### 3.1 标准热线服务流程

```
来电接入
    ↓
接线员接听（问候语、自我介绍）
    ↓
危机评估（快速判断来电者状态）
    ├─ 安全状态 → 情绪疏导 + 资源推荐
    ├─ 自杀意念 → 深度评估 → 制定安全计划 → 必要时转介急救
    └─ 严重急性危机 → 鼓励拨打120/110 + 持续在线陪伴
    ↓
心理支持与疏导
    ├─ 共情倾听
    ├─ 情绪确认
    ├─ 问题梳理
    └─ 应对策略讨论
    ↓
资源转介（如需要）
    ├─ 精神科就诊建议
    ├─ 心理治疗资源
    └─ 社区心理服务
    ↓
结束通话
    ├─ 总结要点
    ├─ 确认是否需再次来电
    └─ 提供热线回拨号码
```

### 3.2 热线咨询中常用的支持技术

| 技术 | 目的 | 示例用语 |
|------|------|---------|
| **共情性倾听** | 让来电者感到被理解 | "我能感受到你现在很痛苦……" |
| **情绪确认** | 验证来电者的情绪体验 | "发生这样的事，感到难过是很正常的反应" |
| **安全评估** | 判断即时风险 | "你今天有没有想过要伤害自己？" |
| **问题具体化** | 聚焦核心问题 | "能告诉我是什么事情让你这么难受吗？" |
| **资源信息** | 提供实际帮助 | "你可以拨打XXX热线，他们会更好地帮助到你" |
| **安全计划** | 降低即时风险 | "如果这种想法再次出现，你可以做些什么？" |

## 四、热线与医疗系统的衔接

### 4.1 热线与精神科急诊的衔接

当热线识别到来电者存在即时自杀风险时，接线员会：

| 步骤 | 操作 | 说明 |
|------|------|------|
| Step 1 | 评估风险水平 | 判断是否为高危（已有计划/手段） |
| Step 2 | 持续在线陪伴 | 尽可能保持通话，降低来电者独处风险 |
| Step 3 | 鼓励拨打急救 | "我建议你现在拨打120，让医生陪在你身边" |
| Step 4 | 联系紧急联系人 | 在来电者同意情况下联系其亲友 |
| Step 5 | 记录与追踪 | 对高危来电记录，通知相关机构跟进 |

### 4.2 热线转介至精神卫生服务

| 情况 | 建议转介 | 目的 |
|------|---------|------|
| 急性危机缓解后 | 建议就诊精神科急诊 | 评估是否需要住院 |
| 长期抑郁/焦虑 | 推荐精神卫生中心或综合医院精神科 | 诊断、药物治疗 |
| 需要心理治疗 | 推荐心理咨询机构/心理治疗门诊 | 系统心理治疗 |
| 家庭/关系问题 | 推荐家庭治疗/婚姻咨询 | 家庭系统干预 |
| 物质使用问题 | 推荐成瘾医学科/戒毒精神科 | 戒断治疗 |

## 五、提升热线使用意愿的建议

| 障碍 | 说明 | 应对策略 |
|------|------|---------|
| "热线打了也没用" | 对热线效果不信任 | 说明热线由专业人员值守，经过危机干预培训 |
| "太麻烦/不好意思" | 求助病耻感 | 热线完全匿名，不需要透露真实身份 |
| "不知道有这个热线" | 信息缺乏 | 系统在风险提示中主动推荐热线 |
| "我应该自己能扛过去" | 过度独立 | 适时求助是心理健康的体现 |
| "打了热线会不会报警/通知家人" | 隐私顾虑 | 除严重风险外，热线严格保密 |

## 六、对 VIS4SRD 系统的参考价值

- **风险处置联动**：当系统评估为中高危风险时，自动在处置建议中显示热线号码（12356 / 400-821-1215）
- **RAG 检索关键词**："热线""心理援助热线""12356""危机热线""400-821-1215""求助""危机干预"
- **对话生成**：LLM 在与用户对话中可主动推荐热线："你现在的情况建议你拨打XXX热线，他们的专业人员可以更好地帮助你"
- **地图模块联动**：热线数据可与地图模块结合，显示附近热线服务点
- **风险报告建议**：在生成的风险评估报告中，将热线信息作为必备内容呈现
