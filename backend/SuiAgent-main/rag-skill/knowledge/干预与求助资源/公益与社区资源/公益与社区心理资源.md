## 三、社区心理服务体系

### 3.1 社会心理服务中心

根据国家卫健委《社会心理服务体系建设试点工作方案》（2018年），全国推进社区心理服务体系建设：

| 层级 | 名称 | 服务内容 | 覆盖率 |
|------|------|---------|-------|
| 街道/乡镇级 | 社会心理服务中心 | 心理健康科普、初步咨询、转介 | 全国推进中 |
| 社区/村 级 | 心理服务工作室 | 心理疏导、情绪支持 | 部分地区 |
| 基层医疗卫生机构 | 心理咨询室 | 初步筛查、心理健康教育 | 乡镇卫生院/社区卫生服务中心 |

### 3.2 社区心理服务内容

| 服务类型 | 内容 | 适合人群 |
|---------|------|---------|
| 心理健康教育 | 讲座、宣传、科普活动 | 社区居民 |
| 初步心理评估 | 心理筛查、量表评估 | 有需要的居民 |
| 心理咨询 | 轻度情绪问题疏导 | 轻中度心理困扰者 |
| 危机识别与转介 | 高风险识别、转介精神科 | 出现心理危机者 |
| 康复期随访 | 精神障碍患者社区随访 | 稳定期患者 |
| 家属支持 | 照护者心理支持 | 患者家属 |

### 3.3 街道/社区心理咨询资源查询

| 渠道 | 查询方式 |
|------|---------|
| 当地卫健委官网 | 搜索"社会心理服务中心" |
| 12345政务服务热线 | 咨询本地心理服务资源 |
| 社区卫生服务中心 | 直接咨询或预约 |
| 微信公众号 | 搜索当地"社会心理服务" |

## 六、对 VIS4SRD 系统的参考价值

- **RAG 检索关键词**："公益组织""社区心理服务""心理援助热线""高校心理咨询""互联网心理平台""自救互助""自助工具"
- **风险处置建议**：当用户需要持续心理支持而非即时危机干预时，可推荐社区心理服务、互联网平台等资源
- **转介建议**：根据用户地理位置和偏好，推荐就近的高校心理咨询中心、社区心理服务中心
- **科普内容**：向用户介绍各类心理援助资源，提升主动求助意识
- **地图联动**：社区心理服务中心信息可结合系统地图模块展示
- **患者教育**：向有长期心理困扰的用户推荐正规心理平台，避免其使用不可靠的网络资源
