# 干预与求助资源主题索引

## 用途
心理干预与求助资源是自杀预防体系的重要组成部分，包括：各级精神卫生机构、心理援助热线、公益组织及社区心理服务。本主题为VIS4SRD系统的风险处置模块提供即时资源导航。

## 主题基本信息
- **主题名称**：干预与求助资源
- **主题代码**：intervention_resources
- **主题描述**：心理机构、医院、热线及公益资源
- **所属分类**：中国心理危机干预资源体系
- **权威来源**：国家卫生健康委员会

## 文档描述
本主题包含6个核心文档：心理卫生机构指南（各级机构分类）、心理机构与医院（全国31省市名录）、各省市心理机构（详细地址电话）、心理援助热线资源、全国热线号码大全、公益与社区心理资源。关键词：精神卫生中心、12356热线、心理援助、社区心理服务、危机热线、转介。

## 子主题列表
- 心理机构与医院：各级精神卫生机构
- 心理援助热线：全国及地方热线
- 公益与社区资源：公益组织和社区资源

## 系统集成
- 地图模块集成心理机构地理位置数据
- 热线数据用于风险处置建议
