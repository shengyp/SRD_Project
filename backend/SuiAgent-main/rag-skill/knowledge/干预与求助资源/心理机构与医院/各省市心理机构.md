## 八、使用说明

### 如何选择合适机构

| 情况 | 建议 |
|------|------|
| 紧急危机 | 拨打危机热线后送医 |
| 中重度心理障碍 | 三甲精神卫生中心 |
| 轻中度心理问题 | 市级精神卫生机构 |
| 青少年问题 | 儿童/青少年心理专科 |
| 综合评估需求 | 三甲医院心理科 |

### 就诊前准备

1. 带上既往病历和检查结果
2. 整理用药情况（名称、剂量）
3. 准备身份证、医保卡
4. 提前预约，避免等待
