# 睡眠与生理主题索引

## 用途
睡眠障碍是自杀的重要风险因素，约75%的抑郁症患者有失眠症状，失眠使自杀风险增加2倍。本主题涵盖：1）失眠与心理健康关系；2）安眠药使用与副作用；3）睡眠生理机制；4）PSQI量表使用。本主题为VIS4SRD系统的睡眠风险筛查提供支持。

## 主题基本信息
- **主题名称**：睡眠与生理
- **主题代码**：sleep_physiology
- **主题描述**：睡眠与生理健康相关内容
- **所属分类**：美国睡眠医学会（AASM）指南
- **权威来源**：AASM睡眠障碍分类、WHO心理健康指南

## 文档描述
本主题包含4个核心文档：失眠与心理健康（失眠-抑郁-自杀三元模型）；安眠药使用与副作用（苯二氮卓类、非苯二氮卓类）；睡眠生理机制（睡眠周期、HPA轴）；PSQI量表。关键词：失眠、PSQI、睡眠障碍、褪黑素、皮质醇、安眠药。

## 子主题列表
