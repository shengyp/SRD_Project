# 失眠与心理

## 用途
失眠与心理健康的关系，包括失眠-抑郁-自杀三元模型。约75%的抑郁症患者有失眠症状，失眠使自杀风险增加2倍。失眠既是心理健康问题的症状，也是其独立风险因素。

## 文档描述
本文档分析失眠与心理健康的关系：1）失眠的定义与分类（入睡困难、睡眠维持困难、早醒）；2）失眠-抑郁-自杀三元模型；3）失眠导致自杀风险增加的机制（神经生物学、认知扭曲）；4）失眠与焦虑、PTSD的关系；5）睡眠卫生教育与CBT-I疗法。本文裨对VIS4SRD系统的价值在于识别失眠相关风险信号和提供睡眠改善建议。
