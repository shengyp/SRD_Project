# 失眠与心理健康

> 来源：American Academy of Sleep Medicine (AASM) ICSD-3 睡眠障碍国际分类；WHO 心理健康指南；Riemann D 等失眠与抑郁症研究综述；Morin CM 等CBT-I系统综述

---

## 一、失眠的定义与分类（ICSD-3）

### 1.1 失眠症核心诊断标准

根据《国际睡眠障碍分类第三版》（ICSD-3），失眠症（Insomnia Disorder）的诊断需满足以下全部条件：

| 条件 | 内容 |
|------|------|
| A. 睡眠主诉 | 入睡困难、睡眠维持困难、早醒或睡眠质量差 |
| B. 日间功能损害 | 至少一项日间症状：疲劳、注意力下降、情绪不稳定、社会/职业功能受损 |
| C. 频率要求 | 症状每周出现≥3晚 |
| D. 病程要求 | 症状持续≥3个月 |
| E. 排除标准 | 排除其他睡眠障碍、物质使用或躯体/精神疾病 |

### 1.2 失眠的亚型分类

| 类型 | 定义 | 特点 |
|------|------|------|
| **慢性失眠** | 症状持续≥3个月，每周≥3晚 | 最常见，影响约10%成年人 |
| **短期失眠** | 症状<3个月 | 通常与急性压力事件相关 |
| **合并症性失眠** | 与精神或躯体疾病共病 | 最常见形式，约80% |
| **原发性失眠** | 非共病性，排除其他原因 | 约占20% |

### 1.3 失眠的临床表现分型

| 亚型 | 核心特征 |
|------|---------|
| **入睡困难型** | 睡眠潜伏期>30分钟，躺在床上辗转反侧 |
| **维持困难型** | 夜间醒来≥3次，或醒来后难以再次入睡 |
| **早醒型** | 比期望时间早醒≥30分钟，且无法再次入睡 |
| **混合型** | 同时存在上述多种表现 |

## 二、失眠与抑郁症的双向关系

### 2.1 失眠与抑郁症的流行病学

失眠与抑郁症之间的关系是当前心理健康研究的重要课题。二者存在显著的双向关系：

| 统计指标 | 数据 |
|---------|------|
| 抑郁症患者中失眠比例 | 约65-75%存在失眠症状 |
| 失眠患者中抑郁症患病率 | 是正常睡眠者的2-5倍 |
| 失眠预测抑郁症风险 | OR值 = 2.8（持续性失眠），1.5（偶发性失眠） |

### 2.2 失眠-抑郁症的相互预测关系

**路径1：失眠 → 抑郁症**

研究表明，睡眠紊乱是抑郁症的重要前置因素：

| 研究发现 | 证据强度 |
|---------|---------|
| 失眠增加抑郁症发病风险 2-5倍 | 强（多项前瞻性队列研究） |
| 入睡困难型失眠预测力最强 | 强 |
| 失眠症状数量与抑郁严重程度正相关 | 中等 |
| 即使控制共病焦虑后仍显著 | 强 |

**可能的机制**：
1. **HPA轴功能失调**：失眠导致皮质醇水平升高，损害海马体神经元
2. **神经递质紊乱**：5-HT、去甲肾上腺素、多巴胺系统异常
3. **前额叶功能受损**：睡眠剥夺损害执行功能，加重负性认知
4. **情绪调节失败**：睡眠不足降低情绪调节能力（DBT研究支持）

**路径2：抑郁症 → 失眠**

抑郁症也可导致或加重失眠：
- 抑郁症的昼夜节律紊乱（生物钟后移）
- 抑郁性认知（反刍思维、担忧）干扰睡眠
- 抑郁相关生理激活（交感神经兴奋）

### 2.3 临床意义

| 场景 | 建议 |
|------|------|
| 抑郁症患者伴失眠 | 失眠是治疗抵抗和复发的重要风险因素 |
| 失眠患者伴抑郁 | 优先治疗失眠（CBT-I）可能改善抑郁 |
| 两者共病 | 联合治疗：SSRI + CBT-I |

## 三、失眠与焦虑障碍的关系

### 3.1 失眠与焦虑的共病

| 焦虑障碍类型 | 失眠共病率 |
|------------|---------|
| 广泛性焦虑障碍（GAD） | 约50-70% |
| 惊恐障碍 | 约40-65% |
| 社交焦虑障碍 | 约40-55% |
| 创伤后应激障碍（PTSD） | 约50-90%（噩梦、梦魇） |

### 3.2 焦虑-失眠的相互机制

```
焦虑状态（担忧、警觉）
        ↓
下丘脑-垂体-肾上腺轴（HPA轴）激活
        ↓
皮质醇和去甲肾上腺素水平升高
        ↓
睡眠启动困难 + 夜间觉醒增加
        ↓
睡眠质量下降
        ↓
前额叶功能受损，情绪调节能力下降
        ↓
焦虑症状加剧（恶性循环）
```

## 四、失眠与自杀风险的研究证据

### 4.1 失眠作为自杀风险因素的证据

失眠与自杀意念、计划和行为之间存在独立关联：

| 研究 | 主要发现 |
|------|---------|
| **Bauer et al. (2020)** | 失眠症状独立预测自杀意念（OR=2.31），即使控制抑郁后仍显著 |
| **Liu et al. (2022)** | 失眠与自杀行为风险增加相关，RR=1.3-1.7 |
| **Sjostrom et al. (2021)** | 主观失眠报告与自杀风险相关，但客观睡眠指标（PSG）的相关性更复杂 |
| **Wojnar et al. (2009)** | 失眠与自杀意念的关联在酒精使用障碍患者中尤为显著 |
| **Nrugham et al. (2008)** | 青少年失眠可预测自杀意念和自杀企图 |

### 4.2 失眠增加自杀风险的机制

| 机制 | 说明 |
|------|------|
| **情绪调节受损** | 睡眠不足损害情绪调节能力，使负面情绪更强烈 |
| **认知收窄** | 睡眠剥夺导致注意力和问题解决能力下降 |
| **神经生物学改变** | HPA轴失调、皮质醇升高与冲动控制下降 |
| **生理激活** | 交感神经兴奋，心率变异性降低 |
| **现实检验能力下降** | 睡眠不足影响对现实的准确判断 |
| **绝望感增加** | 失眠加剧"情况永远不会好转"的信念 |

### 4.3 临床评估建议

在自杀风险评估中，应常规询问睡眠情况：

| 睡眠相关问题 | 评估要点 |
|------------|---------|
| 入睡时间 | 是否超过30分钟？是否存在睡眠预期焦虑？ |
| 夜间醒来 | 醒来次数？醒来后能否再次入睡？ |
| 早醒 | 比平时早醒多久？醒来后的情绪状态？ |
| 睡眠质量 | 主观睡眠满意度？白天疲劳程度？ |
| 噩梦 | 是否频繁出现噩梦？内容是否与创伤或死亡相关？ |
| 睡眠认知 | 对睡眠的灾难化思维（"今晚又睡不着怎么办"） |

## 五、失眠的认知行为治疗（CBT-I）

### 5.1 CBT-I 的核心组成

CBT-I（Cognitive Behavioral Therapy for Insomnia）是失眠的一线循证治疗方法。

| 组件 | 内容 | 作用 |
|------|------|------|
| **睡眠限制疗法** | 限制卧床时间至实际睡眠时间 | 增强睡眠驱动，提高睡眠效率 |
| **刺激控制疗法** | 建立床与睡眠的条件反射 | 消除操作性条件反射（床=清醒） |
| **睡眠卫生教育** | 改善睡眠环境和生活习惯 | 减少影响睡眠的因素 |
| **认知疗法** | 识别和挑战关于睡眠的灾难化思维 | 减少睡眠焦虑 |
| **放松训练** | 渐进式肌肉放松、呼吸训练 | 降低睡前生理激活 |

### 5.2 CBT-I 的疗效证据

| 研究 | 主要结论 |
|------|---------|
| **Morin et al. (2006) JAMA** | CBT-I 对慢性失眠有效，疗效优于药物，持续≥6个月 |
| **Riemann et al. (2017) Sleep Medicine Reviews** | CBT-I 是失眠障碍的一线治疗 |
| **Fu et al. (2022) 中国研究** | CBT-I 对中国失眠患者同样有效 |

### 5.3 CBT-I 自我干预技术

| 技术 | 具体做法 |
|------|---------|
| **刺激控制** | 困了才上床；睡不着就离开床；每天同一时间起床 |
| **睡眠窗口** | 确定平均睡眠时间，限制卧床时间 |
| **30分钟规则** | 如果在床上超过30分钟睡不着，离开床 |
| **避免白天补觉** | 不午睡或限制午睡≤20分钟 |
| **睡前程序** | 建立固定的睡前放松仪式 |

## 六、睡眠卫生教育

### 6.1 睡眠卫生原则

| 类别 | 具体建议 |
|------|---------|
| **睡眠规律** | 每天固定时间睡觉和起床（即使周末） |
| **卧室环境** | 黑暗、安静、凉爽（18-20°C）；舒适的床垫枕头 |
| **光线管理** | 睡前1小时避免强光；早晨接受自然光 |
| **咖啡因限制** | 下午2点后不摄入咖啡因 |
| **酒精限制** | 避免睡前饮酒（虽然可促进入睡但破坏睡眠结构） |
| **尼古丁限制** | 避免睡前吸烟（尼古丁是兴奋剂） |
| **运动** | 规律运动，但避免睡前3小时内剧烈运动 |
| **屏幕时间** | 睡前1小时关闭电子设备 |
| **大餐限制** | 睡前2-3小时不大量进食 |

### 6.2 中国文化背景下的睡眠问题

| 现象 | 说明 |
|------|------|
| "夜猫子"文化 | 工作学习压力大，普遍晚睡，睡眠不足 |
| 中医视角 | 中医将失眠归为"不寐"，讲究"子午觉" |
| 躯体化表达 | 失眠常被表述为"头痛""心脏不舒服" |
| 污名化 | 担心吃安眠药"成瘾"，依从性差 |
