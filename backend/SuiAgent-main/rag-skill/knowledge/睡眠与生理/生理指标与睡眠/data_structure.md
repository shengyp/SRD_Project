# 生理指标与睡眠

## 用途
睡眠生理机制与生理指标，包括：睡眠周期（NREM 1-3期、REM）、昼夜节律、HPA轴激活、皮质醇节律。理解睡眠生理有助于识别失眠的神经生物学机制。

## 关键词
睡眠周期、快速眼动期、NREM、生理节律、褪黑素、皮质醇、HPA轴、昼夜节律

## 权威来源
AASM睡眠障碍分类；睡眠医学教科书

## 文档描述
本文档介绍睡眠生理机制：1）睡眠分期（NREM 1/2/3期和REM期的特征与功能）；2）昼夜节律系统（视交叉上核、褪黑素分泌）；3）HPA轴与睡眠（应激激素对睡眠的影响）；4）睡眠调控的双过程模型。本文裨对VIS4SRD系统的价值在于提供睡眠问题的神经生物学解释。
