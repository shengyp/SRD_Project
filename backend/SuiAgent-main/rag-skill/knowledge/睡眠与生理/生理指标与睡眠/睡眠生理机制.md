# 睡眠生理机制

> 来源：Saper CB 等睡眠-觉醒调节神经机制研究；美国睡眠医学会（AASM）睡眠分期标准；Pace-Schott & Spencer 褪黑素与睡眠研究；Buckley & Schatzberg HPA轴综述

---

## 一、睡眠的神经生理机制

### 1.1 核心调控系统

睡眠-觉醒周期由多个脑区和神经递质系统协同调控：

| 调控系统 | 核心结构 | 关键神经递质 | 主要作用 |
|---------|---------|------------|---------|
| **上行觉醒系统** | 蓝斑（LC）、中缝核、背侧被盖核 | 去甲肾上腺素、5-HT、乙酰胆碱 | 维持觉醒状态 |
| **下丘脑促觉醒区** | 结节乳头体核（TMN） | 组胺 | 促觉醒，阻断时入睡 |
| **下丘脑促睡眠区** | 腹外侧视前区（VLPO） | GABA | 抑制觉醒系统，主动启动睡眠 |
| **昼夜节律起搏器** | 视交叉上核（SCN） | 褪黑素 | 同步内源性节律与外界光照 |
| **食欲素系统** | 下丘脑外侧 | 食欲素（Orexin/Hypocretin） | 稳定觉醒，维持清醒状态 |

### 1.2 睡眠-觉醒的"开关模型"（Flip-Flop Model）

Saper 等（2005, 2010）提出的双稳态开关模型：

```
         觉醒促进系统                    睡眠促进系统
    （去甲肾上腺素/组胺/          （GABAergic VLPO）
      食欲素/乙酰胆碱）
           ↑                              ↑
           ←─────── 互相抑制 ────────→
                   （互斥开关）
```

- **觉醒→睡眠转换**：当睡眠促进区（VLPO）抑制觉醒系统时，进入睡眠
- **食欲素（Orexin）**的稳定作用：防止在不该睡时入睡（缺失导致发作性睡病）
- **失眠的神经机制**：觉醒系统和睡眠系统之间的"开关"失灵，持续激活

## 二、睡眠-觉醒节律的调控（昼夜节律）

### 2.1 视交叉上核（SCN）的作用

| 特性 | 说明 |
|------|------|
| 位置 | 下丘脑前部，视交叉上方 |
| 功能 | 人体主生物钟（master pacemaker） |
| 调控方式 | 接收视网膜感光信号，同步内源节律与24小时光照周期 |
| 同步信号 | 光照（最强）、褪黑素、体温、进食、运动 |
| 节律周期 | 约24.2小时（人类内源性周期） |

### 2.2 影响昼夜节律的因素

| 因素 | 作用方向 | 说明 |
|------|---------|------|
| **光照** | 同步节律（光照→节律前移；暗光→节律后移） | 晨光使生物钟前移；夜晚光照（蓝光）抑制褪黑素 |
| **褪黑素** | 同步节律，促进入睡 | 黑暗刺激松果体分泌；峰值约凌晨2-4点 |
| **体温** | 同步节律 | 体温谷值（约凌晨4点）与睡眠最深阶段同步 |
| **皮质醇** | 觉醒信号 | 峰值（约早晨7-8点）促进觉醒 |
| **社会活动** | 同步节律 | 工作/学习时间表是最强的社会同步信号 |
| **进食时间** | 同步节律 | 限时进食可强化昼夜节律 |

### 2.3 中国人群昼夜节律特点

| 现象 | 说明 |
|------|------|
| 晚睡普遍 | 青少年平均睡眠时间不足，与褪黑素分泌节律后移有关 |
| "社会时差" | 工作日与周末睡眠时间差异大，加重昼夜节律紊乱 |
| 光污染 | 城市夜间人工照明延长光照时间，抑制褪黑素分泌 |
| 轮班工作 | 护士、工厂工人等轮班制人群睡眠障碍高发 |

## 三、睡眠分期（N1/N2/N3/REM）

### 3.1 睡眠阶段详解

根据脑电图（EEG）、眼动图（EOG）和肌电图（EMG），正常睡眠分为两个主要状态：

| 阶段 | 英文缩写 | EEG特征 | 肌张力 | 眼动 | 占比 | 功能 |
|------|--------|--------|-------|------|------|------|
| **非快速眼动睡眠** | NREM | | | | 75-80% | |
| N1（入睡期） | N1 | α波→θ波混合，顶尖波 | 轻度降低 | 慢速眼动 | 2-5% | 过渡阶段 |
| N2（浅睡期） | N2 | 睡眠纺锤波、K复合波 | 进一步降低 | 无眼动 | 45-55% | 记忆巩固 |
| N3（深睡期/慢波睡眠） | N3/SWS | δ波（慢波）为主 | 最低 | 无眼动 | 13-23% | 身体恢复、生长激素分泌 |
| **快速眼动睡眠** | REM | 锯齿波、θ波，类似清醒 | 最低（肌肉弛缓） | 快速眼动 | 20-25% | 情绪记忆加工、梦境 |

### 3.2 睡眠周期结构

| 周期 | 时长 | 特点 |
|------|------|------|
| 第一个周期 | 70-100分钟 | N3（深睡眠）比例高；REM短 |
| 中间周期 | 90-110分钟 | N3逐渐减少；REM逐渐延长 |
| 最后一个周期 | 100-120分钟 | N3减少甚至消失；REM最长 |

**一晚典型睡眠结构**：
```
  第1周期    第2周期    第3周期    第4周期（最后）
  N1→N2→N3→REM→N2→...→N2→N3→REM→N2→...→N2→REM
  (70-100min)  (90min)    (90min)   (100min)
  REM逐渐延长  ↓        ↓
  N3逐渐减少
```

### 3.3 失眠与睡眠结构异常

| 失眠类型 | 睡眠结构改变 |
|---------|------------|
| 原发性失眠 | N1增加；N3减少；入睡后清醒时间（WASO）增加 |
| 抑郁伴失眠 | REM潜伏期缩短（入睡后很快进入REM）；N3减少 |
| 焦虑伴失眠 | 睡眠潜伏期延长；N2比例增加 |
| 睡眠维持困难 | WASO（Wake After Sleep Onset）显著增加 |

## 四、HPA轴与睡眠

### 4.1 HPA轴概述

下丘脑-垂体-肾上腺轴（HPA Axis）是人体主要的应激反应系统：

```
下丘脑（室旁核）
    ↓ CRH（促肾上腺皮质激素释放激素）
垂体前叶
    ↓ ACTH（促肾上腺皮质激素）
肾上腺皮质
    ↓
皮质醇（主要效应激素）
```

### 4.2 皮质醇的昼夜节律

| 时间段 | 皮质醇水平 | 生理作用 |
|-------|-----------|---------|
| 清晨（醒后30分钟内） | **峰值**（全天最高） | 促进觉醒，提供能量 |
| 上午 | 高水平，逐渐下降 | 维持警觉和认知功能 |
| 下午 | 中等水平 | 能量维持 |
| 傍晚至夜间 | **最低值**（午夜前后） | 促进睡眠启动 |

### 4.3 HPA轴失调与失眠

| 机制 | 说明 |
|------|------|
| 慢性压力→HPA轴过度激活 | 皮质醇持续升高，干扰睡眠启动 |
| 皮质醇夜间水平升高 | 睡眠潜伏期延长，夜间易醒 |
| HPA轴反应性增强 | 夜间微觉醒增加（AROP） |
| 海马体损伤 | 慢性高皮质醇损害海马体，影响睡眠依赖性记忆巩固 |
| 失眠→HPA轴进一步失调 | 形成恶性循环：失眠→HPA激活→加重失眠 |

### 4.4 失眠患者HPA轴特点

| 指标 | 失眠患者表现 | 研究证据 |
|------|------------|---------|
| 24小时皮质醇总量 | 升高 | Riemann et al. (2013) |
| 夜间皮质醇 | 显著高于健康对照 | Vgontzas et al. (2013) |
| HPA轴反馈抑制 | 减弱（地塞米松抑制试验） | Steiger et al. (2002) |
| CRH水平 | 升高 | Vgontzas et al. (2001) |

## 五、褪黑素与睡眠

### 5.1 褪黑素的作用

| 特性 | 说明 |
|------|------|
| 分泌部位 | 松果体 |
| 合成原料 | 色氨酸→5-羟色胺→N-乙酰血清素→褪黑素 |
| 主要调节因子 | 光照（视网膜→SCN→松果体） |
| 分泌节律 | 黑暗刺激分泌增加；峰值约凌晨2-4点；白天水平低 |
| 作用受体 | MT1（抑制觉醒）、MT2（调节昼夜节律） |

### 5.2 褪黑素在失眠中的作用

| 应用场景 | 效果 | 推荐剂量 |
|---------|------|---------|
| 睡眠时相延迟障碍（夜猫子） | 节律前移 | 0.5-5mg，睡前1-2小时 |
| 时差反应 | 减少时差症状 | 抵达目的地后睡前服用 |
| 倒班睡眠障碍 | 帮助白天入睡 | 小剂量白天服用 |
| 老年人原发性失眠 | 改善睡眠质量 | 2-5mg |
| 儿童失眠（ADHD等） | 部分有效 | 0.5-3mg |
| 普通失眠 | 轻度改善，证据有限 | 0.5-5mg |

### 5.3 褪黑素与自杀风险的间接关联

褪黑素缺乏可能通过以下途径与自杀风险相关：
- **睡眠障碍**：褪黑素缺乏→昼夜节律紊乱→失眠→自杀风险升高
- **抑郁中介**：褪黑素参与抑郁发病机制（光照治疗有效）
- **HPA轴调节**：褪黑素可抑制HPA轴活性，褪黑素缺乏→皮质醇升高

## 六、睡眠对情绪调节的作用

### 6.1 睡眠剥夺的情绪效应

| 睡眠剥夺类型 | 情绪影响 |
|------------|---------|
| 急性完全睡眠剥夺 | 情绪不稳、负性情绪增加、正性情绪减少 |
| 部分睡眠剥夺 | 类似效应，但程度较轻 |
| 慢性睡眠限制 | 持续负性情绪、焦虑敏感性增加 |
| REM睡眠选择性剥夺 | 情绪调节能力下降，抑郁风险增加 |

### 6.2 睡眠促进情绪调节的机制

| 机制 | 说明 |
|------|------|
| **情绪记忆巩固** | REM睡眠期间，情感负荷记忆被"去敏感化"，减少其情绪强度 |
| **前额叶-杏仁核功能** | 睡眠恢复前额叶对杏仁核的抑制功能，改善情绪调节 |
| **去甲肾上腺素系统重置** | NREM睡眠期间蓝斑神经元静息，重置警觉系统 |
| **皮质醇清除** | 深度睡眠促进夜间皮质醇清除，降低HPA轴负荷 |
| **神经代谢物清除** | NREM睡眠期间脑脊液冲洗，清除代谢废物（β-淀粉样蛋白等） |

### 6.3 临床启示

| 发现 | 临床意义 |
|------|---------|
| 睡眠是情绪调节的基础 | 改善睡眠可直接改善情绪（"睡好才能想好"） |
| 优先处理睡眠问题 | 在综合治疗中，CBT-I应作为优先干预 |
| 睡眠监测有助于预测风险 | PSQI持续高分是情绪障碍和自杀风险的预警信号 |
