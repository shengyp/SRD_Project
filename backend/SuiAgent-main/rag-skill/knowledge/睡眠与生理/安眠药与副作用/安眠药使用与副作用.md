# 安眠药使用与副作用

> 来源：国家药品监督管理局（NMPA）安眠药使用指南；美国FDA安眠药安全警示；WHO 心理健康指南；Ashton CH 苯二氮卓类药物指南

---

## 一、常用安眠药分类

### 1.1 药物分类总览

| 药物类别 | 代表药物 | 作用机制 | 特点 |
|---------|---------|---------|------|
| **苯二氮卓类（BZD）** | 艾司唑仑、氯硝西泮、地西泮 | 增强GABA-A受体 | 强效、成瘾性较高 |
| **非苯二氮卓类（Z-drugs）** | 唑吡坦、右佐匹克隆、扎来普隆 | 选择性GABA-A受体激动 | 半衰期短、成瘾性较低 |
| **褪黑素受体激动剂** | 褪黑素缓释片、雷美替胺 | 激活褪黑素受体 | 调整生物钟、副反应少 |
| **食欲素受体拮抗剂** | 苏沃雷生（suvorexant） | 阻断食欲素信号 | 新型药物，适用于入睡/维持困难 |
| **抗抑郁药类安眠药** | 曲唑酮、米氮平 | 抗组胺/5-HT拮抗 | 适用于抑郁伴失眠 |
| **抗精神病药（超适应症）** | 喹硫平、奥氮平 | 多受体拮抗 | 仅在其他方法失败时使用 |

### 1.2 中国常用安眠药一览

| 药物名称 | 类别 | 半衰期 | 成人常用剂量 | 主要适应症 |
|---------|------|--------|------------|---------|
| 艾司唑仑 | BZD | 10-24h | 1-2mg qn | 入睡困难、维持困难 |
| 氯硝西泮 | BZD | 20-40h | 0.5-2mg qn | 严重失眠、抗惊厥 |
| 地西泮 | BZD | 20-80h | 5-10mg qn | 失眠、焦虑 |
| 唑吡坦 | 非BZD | 0.7-3.5h | 5-10mg qn | 入睡困难 |
| 右佐匹克隆 | 非BZD | 5-6h | 1-3mg qn | 入睡/维持困难 |
| 扎来普隆 | 非BZD | 1-1.3h | 5-10mg qn | 短暂性失眠 |
| 褪黑素 | 褪黑素类 | 短 | 0.5-5mg qn | 睡眠节律障碍 |
| 曲唑酮 | 抗抑郁药 | 3-14h | 25-100mg qn | 抑郁伴失眠 |

## 二、各类安眠药的作用机制

### 2.1 GABA-A受体机制（苯二氮卓类 / 非苯二氮卓类）

| 机制维度 | 说明 |
|---------|------|
| 作用部位 | 中枢神经系统 GABA-A 氯离子通道 |
| 效应 | 增强 GABA 抑制效应，降低神经元兴奋性 |
| 效果 | 镇静、催眠、抗焦虑、肌肉松弛、抗惊厥 |
| 区别 | BZD 对所有 GABA-A 受体亚型无选择性；Z-drugs 有更高选择性 |

### 2.2 褪黑素系统机制

| 机制维度 | 说明 |
|---------|------|
| 作用部位 | 视交叉上核（SCN）褪黑素受体（MT1/MT2） |
| 效应 | 调节昼夜节律，促进睡眠启动信号 |
| 效果 | 改善睡眠时相延迟（夜猫子型）、时差反应 |
| 适用 | 生物钟紊乱型失眠 |

## 三、主要副作用

### 3.1 苯二氮卓类副作用

| 系统 | 副作用 | 发生率 | 备注 |
|------|--------|-------|------|
| **神经系统** | 嗜睡、宿醉效应、头晕、认知损害 | 高（20-60%） | 影响驾驶和操作机械 |
| **依赖性** | 躯体依赖、心理依赖、耐受性 | 高（长期使用>4周） | 突然停药可致戒断症状 |
| **记忆损害** | 顺行性遗忘（用药后记忆缺失） | 中等 | 可逆，停药后恢复 |
| **跌倒风险** | 老年人夜间跌倒、骨折 | 高（老年患者） | FDA黑框警告 |
| **呼吸抑制** | 合并酒精/阿片类药物时加重 | 低（单独使用时） | 严重时危及生命 |
| **异常睡眠行为** | 梦游、睡眠驾驶、睡时进食 | 低 | 唑吡坦更常见 |
| **停药反应** | 反跳性失眠、焦虑加重、肌肉抽搐 | 中等（骤停时） | 应逐步减量 |

### 3.2 非苯二氮卓类（Z-drugs）副作用

相比苯二氮卓类，Z-drugs 的副作用较轻，但仍需注意：

| 系统 | 副作用 | 备注 |
|------|--------|------|
| 神经系统 | 次日嗜睡（宿醉效应）、头晕、头痛 | 剂量依赖 |
| 依赖性 | 相比 BZD 较低，但仍存在 | 长期使用仍可能 |
| 行为异常 | 梦游、睡眠进食、睡眠驾驶 | FDA 已发出警告 |
| 消化系统 | 口苦（口中有金属味，右佐匹克隆多见）、恶心 |

### 3.3 特殊人群用药风险

| 人群 | 风险 | 建议 |
|------|------|------|
| **老年人（≥65岁）** | 跌倒、认知损害、呼吸抑制 | 避免苯二氮卓类；使用最低有效剂量；优先考虑非药物疗法 |
| **孕产妇** | 致畸风险（早孕）、新生儿戒断综合征 | 禁用苯二氮卓类；必要时可选小剂量曲唑酮 |
| **肝功能损害** | 药物代谢减慢，血药浓度升高 | 减量使用；监测不良反应 |
| **肾功能损害** | 药物清除减慢 | 减量；优选不经肾排泄药物 |
| **呼吸疾病（COPD/哮喘）** | 呼吸抑制风险 | 避免使用；如有需要，在监测下使用最低剂量 |
| **物质使用障碍患者** | 交叉依赖、滥用风险高 | 禁用或严格管控；优先CBT-I |

## 四、用药原则

### 4.1 临床用药原则

| 原则 | 具体要求 |
|------|---------|
| **最低有效剂量** | 从最低剂量开始，根据疗效调整 |
| **最短疗程** | 尽量缩短使用时间（一般≤4周）；超过4周需重新评估 |
| **按需给药** | 非每晚服用，仅在必要时使用 |
| **避免骤停** | 长期使用后需逐步减量，以防戒断反应 |
| **定期评估** | 定期评估疗效和不良反应，评估是否继续用药 |
| **综合治疗** | 安眠药作为过渡，配合CBT-I等非药物治疗 |
| **患者教育** | 告知患者药物作用、副作用、成瘾风险及停药方法 |

### 4.2 安眠药使用流程图

```
患者主诉失眠
        ↓
评估失眠类型、共病、用药史
        ↓
诊断评估（排除继发性失眠）
        ↓
一线治疗：睡眠卫生 + CBT-I
        ↓
效果不佳/中重度失眠
        ↓
短期/按需使用安眠药（低剂量）
        ↓
同时继续 CBT-I
        ↓
定期评估（2-4周）
        ↓
症状改善 → 逐步减量 → CBT-I维持
症状未改善 → 重新评估诊断 → 调整方案
```

## 五、停药方法

### 5.1 停药指征

| 情况 | 说明 |
|------|------|
| 失眠症状改善 | 睡眠质量满意，维持≥4周 |
| 心理/行为问题已解决 | 压力源消除，睡眠习惯改善 |
| 患者主动要求 | 患者有意愿停药，愿意配合减量计划 |
| 不良反应严重 | 难以耐受不良反应 |
| 长期使用≥4周 | 为预防依赖，主动规划减量 |

### 5.2 减量方案

**原则**：
1. 速度要慢：每1-2周减少原剂量的10-25%
2. 形式多样：可采用隔日服药→逐渐减少频次→减量
3. 心理支持：告知可能出现的反跳症状，减少焦虑
4. 替代方法：减量期间加强CBT-I、睡眠卫生支持

| 步骤 | 方法 | 时长 |
|------|------|------|
| Step 1 | 记录睡眠日记 | 2周 |
| Step 2 | 隔日服药（减少给药频次） | 2-4周 |
| Step 3 | 每次减少剂量的25% | 每1-2周调整 |
| Step 4 | 逐步拉长服药间隔 | 直至完全停药 |
| Step 5 | 停药后监测4周 | 关注反跳性失眠 |

### 5.3 停药反应的处理

| 反跳症状 | 处理方法 |
|---------|---------|
| 反跳性失眠 | 暂时性睡眠恶化，可恢复到上一剂量，待稳定后再减 |
| 焦虑加重 | 正念放松训练；必要时短期使用抗焦虑药替代 |
| 躯体症状 | 逐步肌肉放松；一般数天内自行缓解 |
