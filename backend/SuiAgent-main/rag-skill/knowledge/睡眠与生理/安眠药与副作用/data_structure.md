# 安眠药与副作用

## 用途
常用安眠药类型及副作用说明，包括：苯二氮卓类、非苯二氮卓类Z-drugs、褪黑素受体激动剂。需注意安眠药使用与自杀风险的复杂关系。

AASM睡眠障碍分类；WHO心理健康指南

## 文档描述
本文档介绍常用安眠药：1）苯二氮卓类（安定类）的镇静机制、依赖风险、过量风险；2）非苯二氮卓类Z-drugs（唑吡坦、扎来普隆）相对安全性；3）安眠药与自杀风险（过量风险、物质滥用共病）；4）安全处方原则。本文裨对VIS4SRD系统的价值在于识别物质滥用风险和提供安全用药建议。
