# 情绪调节策略

## 用途
循证情绪调节技术，包括：正念减压（MBSR）、认知重评、问题解决训练、情绪表达。良好的情绪调节能力是心理健康的保护因素，情绪调节困难是自杀风险信号。

## 文档描述
本文档介绍循证情绪调节策略：1）正念技术（呼吸觉察、身体扫描、三步正念空间）；2）认知重评（换角度看问题、积极重构）；3）情绪表达（写信、写日记）；4）问题解决训练（明确问题、生成方案、评估执行）；5）接纳与承诺（ACT）。本文裨对VIS4SRD系统的价值在于提供情绪自助技能指导和RAG对话干预建议。
