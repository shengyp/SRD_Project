# 心理健康素养主题索引

## 用途
心理健康素养是预防自杀的重要保护因素，包括：正确认识心理健康问题、识别风险信号、掌握自助技能。本主题涵盖：1）WHO心理健康标准；2）认知扭曲与CBT；3）情绪调节策略；4）心理健康问题与应对。本主题为VIS4SRD系统的科普教育模块提供内容支持。

## 主题基本信息
- **主题名称**：心理健康素养
- **主题代码**：mental_health_literacy
- **主题描述**：心理健康基础知识与技能培训
- **所属分类**：WHO心理健康素养指南
- **权威来源**：WHO心理健康标准；CBT循证研究

## 文档描述
本主题包含4个核心文档：WHO心理健康十大标准（健康定义、心理弹性标准）；认知扭曲与CBT（10种认知扭曲、认知重构技术）；情绪调节策略（正念、认知重评）；心理健康问题与应对（常见问题分类、自助策略）。关键词：心理健康、CBT、认知扭曲、情绪调节、正念、心理韧性。

## 子主题列表
- 心理健康标准：WHO心理健康十大标准、风险等级划分
- 认知扭曲与CBT：十种认知扭曲类型、CBT原理
- 情绪调节策略：情绪调节技术（正念、认知重评等）
- 心理健康问题与应对：常见心理问题分类、识别与转介

## 关联概念
- CBT（认知行为疗法）：循证心理治疗方法
- DBT（辩证行为疗法）：情绪调节技术
- 正念减压（MBSR）：情绪调节方法
