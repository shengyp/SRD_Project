# 认知扭曲与CBT

## 用途
十种认知扭曲类型与CBT认知行为疗法原理，包括：非黑即白思维、灾难化、读心术、情绪推理等。认知扭曲是抑郁和自杀风险的重要认知因素，CBT是循证治疗方法。

## 关键词
认知扭曲、CBT、认知行为疗法、认知重构、自动思维、核心信念、非黑即白、灾难化、读心术

## 权威来源
Beck AT (1979) 认知疗法；Burns DD (1980) 情绪困扰的感觉良好技术

## 文档描述
本文档介绍认知扭曲与CBT：1）十种认知扭曲类型（非黑即白、灾难化、读心术、情绪推理、过度概括、选择性注意、贴标签、个人化、应该陈述、情绪化归因）；2）CBT基本原理（认知-情绪-行为三角）；3）认知重构四步法（识别-评估扭曲-生成替代-验证）；4）CBT在自杀预防中的应用。本文裨对VIS4SRD系统的价值在于识别用户认知扭曲和提供认知重构建议。
