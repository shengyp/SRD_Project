# 心理健康问题与应对

> 本文档提供常见心理健康问题的识别、评估和应对策略指南。

---

## 一、常见心理健康问题分类

### 1.1 情绪障碍

| 障碍类型 | 主要特征 | 核心症状 |
|---------|---------|---------|
| 重性抑郁障碍 | 持续两周以上的抑郁情绪 | 情绪低落、兴趣减退、自我价值感低 |
| 双相情感障碍 | 抑郁与躁狂交替 | 抑郁期与精力充沛/冲动期交替 |
| 恶劣心境 | 长期轻中度抑郁 | 持续的消极情绪，但功能受损较轻 |

### 1.2 焦虑障碍

| 障碍类型 | 主要特征 | 核心症状 |
|---------|---------|---------|
| 广泛性焦虑障碍 | 过度担忧，难以控制 | 对各种事务的持续性担忧 |
| 惊恐障碍 | 反复惊恐发作 | 心悸、出汗、窒息感、濒死感 |
| 社交焦虑障碍 | 对社交情境的恐惧 | 害怕被审视、评价 |
| 特定恐惧症 | 对特定对象的恐惧 | 回避恐惧对象 |

### 1.3 自杀相关问题

- **自杀意念**：有死的想法，但无行动计划
- **自杀计划**：有具体的死亡计划
- **自杀准备**：已开始准备实施计划
- **自杀未遂**：有目的的自我伤害行为

## 二、问题识别与评估

### 2.1 评估框架

```
1. 症状识别
   ↓
2. 严重程度评估
   ↓
3. 功能损害评估
   ↓
4. 自杀风险评估
   ↓
5. 资源与支持评估
```

### 2.2 功能损害评估维度

| 维度 | 评估内容 |
|------|---------|
| 社会功能 | 与他人交往、社交活动 |
| 职业功能 | 工作表现、学习能力 |
| 日常生活 | 自理能力、生活安排 |
| 家庭功能 | 家庭关系、亲子互动 |

### 2.3 评估工具选择

| 目的 | 推荐工具 |
|------|---------|
| 抑郁筛查 | PHQ-9 |
| 焦虑筛查 | GAD-7 / SAS |
| 自杀风险 | C-SSRS / 心理急救 |
| 综合评估 | MINI |

## 三、应对策略

### 3.1 自我帮助策略

| 策略 | 适用问题 | 操作要点 |
|------|---------|---------|
| 规律作息 | 抑郁、焦虑 | 固定起床时间、保证睡眠 |
| 运动锻炼 | 抑郁、焦虑 | 每周3-5次、每次30分钟 |
| 社交活动 | 抑郁、孤独 | 主动联系他人、参加集体活动 |
| 正念练习 | 焦虑、压力 | 每日冥想、身体扫描 |
| 认知重构 | 抑郁、焦虑 | 识别消极思维、寻找替代解释 |

### 3.2 何时寻求专业帮助

| 情况 | 建议 |
|------|------|
| 症状持续超过2周 | 寻求专业评估 |
| 功能明显受损 | 预约心理咨询/精神科 |
| 有自杀想法/计划 | 立即拨打危机热线 |
| 出现自伤行为 | 紧急就医 |
| 严重影响日常生活 | 考虑更高强度的治疗 |

### 3.3 常见误解澄清

| 误解 | 正确认识 |
|------|---------|
| "看心理医生就是精神病" | 心理健康和身体健康一样重要 |
| "我应该能自己解决" | 求助是勇敢的表现 |
| "吃点药就好了" | 药物+心理治疗效果更佳 |
| "心理咨询很贵" | 很多机构提供低价或免费服务 |

## 四、心理健康维护

### 4.1 预防性措施

1. **保持规律生活**：充足睡眠、规律饮食、适度运动
2. **培养兴趣爱好**：丰富生活、增加成就感
3. **建立社交支持**：维护家庭和朋友关系
4. **学会压力管理**：合理安排时间、设定边界
5. **定期心理检查**：像体检一样关注心理状态

### 4.2 危机预警信号

| 早期信号 | 危险信号 |
|---------|---------|
| 情绪明显低落 | 谈论死亡/自杀 |
| 睡眠问题加重 | 赠送物品/告别 |
| 社交退缩 | 获取自杀工具 |
| 自我否定增加 | 突然的情绪好转（可能是决定后的平静） |

| 资源类型 | 适用情况 | 获取方式 |
|---------|---------|---------|
| 心理咨询师 | 一般心理问题 | 医院心理科、心理咨询机构 |

| 危机干预热线 | 自杀风险 | 24小时危机热线 |
