# 心理健康问题与应对

## 用途
常见心理问题分类、识别与转介指南，包括：抑郁症、焦虑症、睡眠障碍、物质滥用等常见问题的识别要点、严重程度判断及转介建议。正确的识别和转介是自杀预防的重要环节。

## 文档描述
本文档介绍常见心理问题与应对：1）抑郁症识别要点（情绪低落、兴趣减退、症状持续2周以上）；2）焦虑症识别要点（过度担忧、躯体症状）；3）睡眠障碍识别；4）物质滥用识别；5）转介指征（自伤行为、严重功能损害）；6）非专业人员的支持技巧。本文裨对VIS4SRD系统的价值在于帮助用户识别心理健康问题和知道何时需要专业帮助。
