# 心理健康标准

## 用途
WHO心理健康十大标准与风险等级划分，包括：心理健康的定义、评估维度（情绪、认知、行为、社会功能）、风险等级判定（正常/关注/预警/危机）。

## 文件说明
- 心理健康标准.md - WHO心理健康标准与风险等级完整文档

## 关键词
心理健康标准、WHO十大标准、风险等级、心理弹性、情绪健康、社会功能、评估维度

## 权威来源
WHO心理健康指南（2019）；《中国心理健康素养研究报告》

## 文档描述
本文档介绍WHO心理健康标准：1）心理健康定义（不仅是无心理疾病，还包括积极心理状态）；2）心理健康十大标准（情绪调节、压力管理、社会支持等）；3）心理健康评估维度（情绪、认知、行为、社会功能）；4）风险等级划分（正常/关注/预警/危机）；5）心理健康促进策略。本文裨对VIS4SRD系统的价值在于提供心理健康评估的框架和风险等级判定依据。
