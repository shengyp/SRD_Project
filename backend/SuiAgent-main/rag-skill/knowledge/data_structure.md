# VIS4SRD RAG 知识库总索引

## 设计目标
- 该知识库服务于新 agent 的本地 RAG 检索。
- 物理结构保持两层：`主题目录 -> 文档文件`，便于 agent 先选主题、再选文件。
- 语义结构保留三层：`主题 -> 子主题 -> 关键词`，便于前端展示与检索提示。
- 子主题和关键词不再作为物理目录，而是写入索引文件和 `knowledge_catalog.json` 元数据。

## 使用约定
- 当用户查询某类问题时，先根据“主题说明”选择最相关的主题目录。
- 进入主题目录后，再结合“子主题 / 关键词 / 文件用途”选择目标文件。
- 如果用户问题跨多个主题，可返回多个候选文件。

## 主题总览

  - 成人急诊处置

## 检索提示
- 优先使用短查询，如“青少年抑郁症状”“ASQ 急诊流程”“988 热线服务范围”。
- 若用户问题带有人群、场景、风险等级，优先把这些线索映射到子主题。
- 若用户需要数据结论，优先进入 `Mental Health Statistics & Reports`。
- 若用户需要规范流程，优先进入 `Mental Health Clinical Guidelines` 或 `Mental Health Suicide Prevention`。
- 若用户需要科普解释，优先进入 `Mental Health Disorders`。

## 展示层说明
- 前端如需展示三级结构，请读取同目录下的 `knowledge_catalog.json`。
- 该 JSON 保留主题、子主题、关键词、文件、别名和用途说明。
