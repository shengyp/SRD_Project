> 来源：Zung WWK. (1965). A SANITY score for detecting depression. Lancet；Zung WWK. (1971). Depression in the normal and depressed population. Arch Gen Psychiatry；Zung WWK. (1974). Assessment of non-psychotic patients with a self-rating depression scale. Psychosomatics

## 一、Zung焦虑自评量表（SAS）概述

### 1.1 量表背景

Zung 焦虑自评量表（Self-Rating Anxiety Scale, SAS）由 Zung W.W.K. 于 1971 年编制，是评估焦虑状态的经典自评量表。

| 属性 | 内容 |
|------|------|
| 编制者 | Zung WWK（美国杜克大学） |
| 编制年份 | 1971年 |
| 题数 | 20题 |
| 完成时间 | 3-5分钟 |
| 评分方式 | 1-4分（反向计分题：4-1分） |
| 总分范围 | 20-80分 |

## 四、反向计分题目说明

SAS 和 SDS 均包含正向计分题和反向计分题（5题为反向计分），计算总分时需进行转换：

### 4.1 SAS反向计分题目

| 题号 | 原因 |
|------|------|
| 第5题 | "我觉得一切都很好"——正常时为高焦虑时反而得分低 |
| 第9题 | "我容易安静坐着"——焦虑时坐立不安，正常时反而平静 |
| 第13题 | "我吸气呼气都感到很容易"——焦虑时呼吸困难，正常时容易 |
| 第17题 | "我的手常常是干燥温暖的"——焦虑时常手心出汗，正常时干燥温暖 |
| 第19题 | "我容易入睡并且一夜睡得很好"——焦虑时失眠，正常时睡眠好 |

**反向计分转换**：

| 原答案 | 转换得分 |
|-------|---------|
| ①没有或很少时间 | 4分 |
| ②小部分时间 | 3分 |
| ③相当多时间 | 2分 |
| ④绝大部分或全部时间 | 1分 |

### 4.2 SDS反向计分题目

| 题号 | 原因 |
|------|------|
| 第2题 | "我觉得一天中早晨最好"——抑郁时晨重夜轻，晨间感觉差 |
| 第5题 | "我吃得跟平常一样多"——抑郁时食欲减退，正常时食欲正常 |
| 第6题 | "我的性功能正常"——抑郁时常减退 |
| 第11题 | "我的头脑跟平常一样清楚"——抑郁时思维迟缓 |
| 第12题 | "我觉得经常做的事情并没有困难"——抑郁时活动减少，感到困难 |
| 第14题 | "我对未来感到有希望"——抑郁时对未来绝望 |
| 第16题 | "我觉得作出决定是容易的"——抑郁时犹豫不决 |
| 第17题 | "我觉得自己是个有用的人，有人需要我"——抑郁时无价值感 |
| 第18题 | "我的生活过得很有意思"——抑郁时兴趣丧失 |
| 第20题 | "我仍旧喜爱自己平时喜爱的东西"——抑郁时兴趣减退 |

## 五、标准分换算公式

### 5.1 计算方法

SAS 和 SDS 的原始总分范围为 **20-80分**。由于20题的量表理论最低分为20，为使结果与百分制一致，需将原始分换算为标准分：

$$
\text{标准分（SDS Index）} = \text{原始总分} \times 1.25
$$

**标准分范围**：25-100分

### 5.2 分数解读示例

| 原始总分 | 标准分 | SAS 评级 | SDS 评级 |
|---------|--------|---------|---------|
| 20-40 | 25-50 | 正常范围 | 正常范围 |
| 41-42 | 51-52.5 | 轻度焦虑 | 轻度抑郁 |
| 43-49 | 53.75-61.25 | 中度焦虑 | 中度抑郁 |
| 50-59 | 62.5-73.75 | 中重度焦虑 | 中重度抑郁 |
| 60-79 | 75-100 | 重度焦虑 | 重度抑郁 |

## 六、评分标准

### 6.1 SAS 评分标准

| 标准分范围 | 焦虑程度 | 建议 |
|-----------|---------|------|
| **< 50** | 正常范围 | 无需干预 |
| **50-59** | 轻度焦虑 | 心理教育、放松训练 |
| **60-69** | 中度焦虑 | 心理治疗、药物治疗 |
| **≥ 70** | 重度焦虑 | 积极药物治疗、评估精神科转诊 |

### 6.2 SDS 评分标准

| 标准分范围 | 抑郁程度 | 建议 |
|-----------|---------|------|
| **< 50** | 正常范围 | 无需干预 |
| **50-59** | 轻度抑郁 | 心理教育、关注随访 |
| **60-69** | 中度抑郁 | 心理治疗或药物治疗 |
| **≥ 70** | 重度抑郁 | 积极治疗、评估转诊 |

### 6.3 SDS 与 PHQ-9 对照

| SDS标准分 | PHQ-9 总分（等效） | 严重程度 |
|-----------|-------------------|---------|
| < 50 | 0-4 | 无或极轻微 |
| 50-59 | 5-9 | 轻度 |
| 60-69 | 10-14 | 中度 |
| 70-79 | 15-19 | 中重度 |
| ≥ 80 | 20-27 | 重度 |

## 七、局限性

| 量表 | 局限性 |
|------|-------|
| **SAS** | 区分焦虑类型（广泛性焦虑/惊恐障碍/社交焦虑）能力有限；躯体症状条目易与躯体疾病混淆 |
| **SDS** | 对非典型抑郁（如嗜睡/食欲增加）敏感度较低；不能区分抑郁与恶劣心境；不包含自杀意念直接评估 |
| **两者共有** | 依赖主观报告；不能替代临床诊断；需要结合功能损害评估；自评量表存在伪装（夸大或隐瞒）可能性 |
