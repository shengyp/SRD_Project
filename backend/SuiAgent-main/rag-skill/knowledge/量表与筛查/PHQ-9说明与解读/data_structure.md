# PHQ-9说明与解读

## 用途
患者健康问卷-9（PHQ-9）是国际通用的抑郁筛查量表，包含9个题目，第9题专门评估自杀意念。PHQ-9总分5/10/15/20分对应轻/中/重/极重度抑郁。第9题≥1分提示需关注自杀风险。

## 文档描述
本文档详细介绍PHQ-9量表：1）量表结构（9题，评估过去2周的症状）；2）评分标准（0-4无，5-9轻，10-14中，15-19重，20-27极重）；3）第9题解读（评估自杀意念，需单独关注）；4）临床应用（筛查、严重程度评估、治疗效果监测）；5）中文版信效度。本文裨对VIS4SRD系统的价值在于标准化PHQ-9评分解读和自杀风险信号识别。
