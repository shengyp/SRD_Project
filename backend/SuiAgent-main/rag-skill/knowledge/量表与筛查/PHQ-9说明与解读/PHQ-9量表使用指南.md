# PHQ-9量表使用指南

> 来源：Kroenke K, Spitzer RL, Williams JB. (2001). The PHQ-9: validity of a brief depression screening measure. Journal of General Internal Medicine；Pfizer Inc. PHQ-9/GAD-7 官方使用指南；中华医学会精神医学分会《中国抑郁障碍防治指南（2025版）》

---

## 一、PHQ-9概述

### 1.1 量表背景

患者健康问卷-9（Patient Health Questionnaire-9, PHQ-9）是美国 Pfizer 公司于 1999 年在患者健康问卷（PHQ）基础上开发的抑郁筛查量表，由 Spitzer、Williams、Kroenke 等编制。

| 属性 | 内容 |
|------|------|
| 编制机构 | Pfizer Inc. /哥伦比亚大学 |
| 原始语言 | 英语（已翻译为100+语言） |
| 中文版本 | 由四川大学华西医院翻译并验证 |
| 量表性质 | 自评量表 |
| 题目数量 | 9题 |
| 完成时间 | 2-5分钟 |
| 评分方式 | 0-3分 Likert 4级评分 |

---

## 二、PHQ-9完整内容

**指导语**：在过去**两周**里，您是否受到以下问题的困扰？

| 题号 | 问题内容 | 0=完全不会 | 1=好几天 | 2=一半以上时间 | 3=几乎每天 |
|------|---------|-----------|---------|--------------|-----------|
| **1** | 做事时提不起劲或没有兴趣 | | | | |
| **2** | 感到心情低落、沮丧或绝望 | | | | |
| **3** | 入睡困难、睡不安稳或睡眠过多 | | | | |
| **4** | 感觉疲倦或没有活力 | | | | |
| **5** | 食欲不振或吃太多 | | | | |
| **6** | 觉得自己很糟，或觉得自己很失败，或让自己或家人失望 | | | | |
| **7** | 对事物专注有困难，例如看报纸或看电视时 | | | | |
| **8** | 动作或说话速度缓慢到别人可察觉到的程度，或正好相反——坐立不安、动来动去比平常更严重 | | | | |
| **9** | 有不如死掉或用某种方式伤害自己的念头 | | | | |

**总分范围**：0-27分

---

## 三、评分标准与严重程度分级

### 3.1 总分计算

PHQ-9 总分 = 第1题至第9题得分之和（0-27分）

### 3.2 严重程度分级（临床决策阈值）

| PHQ-9总分 | 抑郁严重程度 | 处置建议 |
|-----------|------------|---------|
| **0-4** | 无或极轻微 | 监测，可能不需要干预 |
| **5-9** | 轻度 | 关注，随访；考虑心理教育 |
| **10-14** | 中度 | 制定治疗计划；心理治疗和/或药物治疗 |
| **15-19** | 中重度 | 积极药物治疗+心理治疗 |
| **20-27** | 重度 | 立即开始药物治疗；强烈推荐心理治疗；评估共病 |

### 3.3 敏感性特异性数据

| 诊断切点 | 敏感性 | 特异性 | PPV（阳性预测值） | NPV（阴性预测值） |
|---------|--------|--------|----------------|----------------|
| ≥10 | 88% | 88% | 75% | 95% |
| ≥11 | 83% | 89% | 78% | 92% |
| ≥12 | 78% | 91% | 80% | 90% |
| ≥15 | 65% | 95% | 88% | 83% |

> 注：多项研究表明，**≥10分**是在初级保健人群中筛查重性抑郁障碍的最佳切点（Kroenke et al., 2001）。

## 四、第9题（自杀意念）的重要性

### 4.1 第9题的临床意义

PHQ-9 第9题是整个量表的**核心预警题**，直接评估自杀意念：

| 选项 | 含义 | 临床意义 |
|------|------|---------|
| **0** = 完全不会 | 无自杀意念 | 关注其他9项 |
| **1** = 好几天 | 偶发轻生意念 | 轻度风险，关注随访 |
| **2** = 一半以上时间 | 反复出现 | 中度风险，需进一步评估 |
| **3** = 几乎每天 | 持续存在 | 高风险，立即评估安全 |

### 4.2 第9题阳性时的处理流程

```
PHQ-9 第9题得分 ≥ 1
        ↓
询问具体内容：
  - 自杀的念头有多频繁？
  - 是否已有计划？
  - 是否有准备行动？
        ↓
根据回答进行风险分层：
  - 无计划 → 低危 → 心理支持 + 随访
  - 有计划但无准备 → 中危 → 心理治疗 + 密切随访
  - 有准备 → 高危 → 立即转介精神科
```

### 4.3 PHQ-9与自杀风险的关系

| 研究发现 | 证据 |
|---------|------|
| PHQ-9总分≥15时，自杀死亡风险显著升高 | 强 |
| 第9题阳性者（≥1分）自杀风险是无症状者的**4-6倍** | 强 |
| 第9题得分为3时，自杀死亡风险进一步升高 | 强 |
| PHQ-9第9题是自杀意念的独立预测因素 | 强 |

## 五、PHQ-2快速筛查方法

### 5.1 PHQ-2内容

对于时间有限的场景，可先使用 PHQ-2 快速筛查：

| 题号 | 问题内容 |
|------|---------|
| **PHQ-2 Q1** | 对事物缺乏兴趣或乐趣 |
| **PHQ-2 Q2** | 情绪低落、沮丧或绝望 |

评分：0-6分，阳性切点为≥3分。

### 5.2 PHQ-2 临床流程

```
PHQ-2 筛查（2题，<1分钟）
        ↓
得分 < 3（阴性）
→ 排除当前抑郁可能性
        ↓
得分 ≥ 3（阳性）
→ 进一步完成 PHQ-9 全量表评估
```

| 指标 | PHQ-2 数据 |
|------|-----------|
| 敏感性 | 83%（以PHQ-9为参照标准） |
| 特异性 | 90% |
| 阳性似然比 | 8.3 |
| 阴性似然比 | 0.19 |

## 六、PHQ-9的局限性

| 局限性 | 说明 | 应对策略 |
|--------|------|---------|
| 依赖主观报告 | 无法区分躯体疾病导致的疲劳等症状 | 结合临床评估 |
| 无法诊断双相抑郁 | 对躁狂史患者需谨慎 | 筛查双相障碍家族史 |
| 文化适应性 | 不同文化背景下对情绪词汇的理解差异 | 本地化验证 |
| 不能替代临床诊断 | 是筛查工具，非诊断工具 | 阳性者需进一步临床评估 |
| 对轻度抑郁过度敏感 | 可能将正常悲伤也标记为阳性 | 结合功能损害评估 |
| 第9题局限性 | 自杀意念不等同于自杀行为 | 需结合行为和其他风险因素 |

## 七、临床处置建议（按严重程度）

### 7.1 轻度抑郁（5-9分）

| 建议 | 说明 |
|------|------|
| 心理教育 | 告知抑郁的性质和自我调节方法 |
| 积极随访 | 2周内复诊评估 |
| 生活方式调整 | 运动、睡眠、社会支持 |
| 监测 | 观察是否进展 |

### 7.2 中度抑郁（10-14分）

| 建议 | 说明 |
|------|------|
| 心理治疗 | CBT、IPT 为首选 |
| 药物治疗 | 可考虑 SSRI（如症状≥6周或患者倾向） |
| 缩短随访间隔 | 每1-2周评估 |

### 7.3 中重度抑郁（15-19分）

| 建议 | 说明 |
|------|------|
| 药物治疗 | 首选SSRI；如1-2种SSRI无效，考虑SNRI或安非他酮 |
| 联合心理治疗 | 药物治疗 + CBT/IPT |
| 缩短随访间隔 | 每周评估 |

### 7.4 重度抑郁（20-27分）

| 建议 | 说明 |
|------|------|
| 积极药物治疗 | 可能需要更高剂量或联合用药 |
| 心理治疗 | 联合治疗 |
| 评估住院需求 | 严重功能损害、有自杀意念/计划者 |
| 评估共病 | 双相、精神病性症状、物质使用 |
| 及时转介精神科 | 超出全科处理范围 |
