# 哥伦比亚自杀严重程度评定量表

> 来源：Posner K, Brent D, Lucas C, et al. Columbia-Suicide Severity Rating Scale (C-SSRS). Columbia University; Mann JJ et al. (2008). Suicide prevention strategies. JAMA；国际自杀预防协会（IASP）推荐工具

---

## 一、C-SSRS简介

### 1.1 量表背景

哥伦比亚自杀严重程度评定量表（Columbia Suicide Severity Rating Scale, C-SSRS）由美国哥伦比亚大学 Posner、Kennedy 等团队于2008年开发，是目前**国际应用最广泛的自杀风险标准化评估工具**。

| 属性 | 内容 |
|------|------|
| 编制机构 | 美国哥伦比亚大学精神病学系 |
| 编制年份 | 2008年 |
| 主要开发者 | Posner K, Brent D, Lucas C et al. |
| 版本 | 筛选版（Screening Version）/ 评估版（Assessment Module）/ Lifetime/Recent版 |
| 题量 | 因版本而异（4-30+题） |
| 评估时长 | 筛选版约2-3分钟；完整评估约10-15分钟 |
| 是否需要精神科背景 | **否**（无精神科背景人员也可使用） |
| 商业使用 | **免费**（可用于非商业目的） |
| 语言版本 | 100+语言（含简体中文） |

### 1.2 C-SSRS的国际地位

| 机构 | 推荐情况 |
|------|---------|
| **美国FDA** | 要求抗抑郁药临床试验中使用 C-SSRS 作为自杀风险评估标准 |
| **WHO** | 纳入 mhGAP 自杀预防工具包 |
| **IASP**（国际自杀预防协会） | 推荐作为自杀风险评估的核心工具 |
| **JCAHO** | 美国医疗机构评审联合委员会要求评估自杀风险 |
| **NIMH** | 列为自杀研究标准评估工具 |

## 二、筛选版（Screening Version）核心问题

C-SSRS 筛选版包含4个核心问题，适合快速筛查：

### 2.1 筛选版问题

| 序号 | 问题 | 核心评估内容 |
|------|------|------------|
| **1** | 在过去一个月中，你是否有过**自杀意念**——即想过自杀或希望自己已经死去？ | 自杀意念的存在 |
| **2** | 在过去一个月中，当你想到活着时，你是否**希望自己已经死去**——即使你并不真的打算采取行动？ | 被动自杀意念 |
| **3** | 在过去一个月中，你是否**想过**或**考虑过**采取某种方式伤害自己并杀死自己？ | 主动自杀意念 |
| **4** | 你是否**已经开始了**某个自杀计划，或已经采取了某种准备行动来伤害自己？ | 自杀计划与准备 |
| **5** | 你最近是否有过**自杀行为**？（自残伴自杀意图） | 自杀行为 |

> 注：以上为筛选版核心问题，C-SSRS 评估版（Assessment Module）会对每个维度进行更详细的评估。

### 2.2 筛选版的临床决策

| 问题 | 回答"是"的处理建议 |
|------|-------------------|
| Q1-Q2（被动意念） | 进一步评估；关注随访 |
| Q3（有主动意念但无计划） | 积极评估；确定频率/强度/可及性 |
| Q4（有计划或准备行为） | 高危；立即安全评估；考虑转介 |
| Q5（有行为） | 极高危；立即干预；转介精神科/急诊 |

## 三、评估版（Assessment Module）主要内容

C-SSRS 评估版对自杀意念和行为进行了**多维度分级**，是目前最系统的自杀风险评估框架。

### 3.1 自杀意念类型（Ideation）

| 等级 | 名称 | 定义 | 严重程度 |
|------|------|------|---------|
| **0** | 无 | 无自杀意念 | — |
| **1** | 被动意念——其他方式死去 | 想过自己死了，但不想活着；无采取行动的意念 | 低 |
| **2** | 主动意念——无行为意图 | 有过想自杀的想法，但**没有**计划或打算采取行动 | 中 |
| **3** | 主动意念——行为意图不明确 | 有过想自杀的想法，**意图模糊** | 中-高 |
| **4** | 主动意念——有计划但无准备行动 | 有自杀计划，但**没有**开始准备** | 高 |
| **5** | 主动意念——有计划并有准备行动 | 有自杀计划，且**已经准备**（如买药、找工具、留遗书） | 极高 |

### 3.2 自杀行为类型（Behavior）

| 行为类型 | 定义 | 严重程度 |
|---------|------|---------|
| **准备行为** | 为实施自杀做准备（购买药物、写信、遗嘱等），但未实施 | 高 |
| **中断的自杀行为** | 在实施自杀行为的过程中，被自己或他人阻止 | 极高 |
| **未遂自杀行为** | 实施了有自杀意图的非致死性行为（可能造成伤害） | 极高 |
| **自杀死亡** | 实施了有自杀意图的行为，导致死亡 | 极高 |

### 3.3 其他评估维度

| 维度 | 评估内容 |
|------|---------|
| **频率** | 自杀意念或行为出现的次数 |
| **持续时间** | 每次自杀意念持续多长时间 |
| **可及性** | 获取自杀手段的容易程度 |
| **可及性控制** | 是否有可行的手段限制（如家中无药物） |
| **具体意图** | 是否明确表示"如果……我就会死" |
| **警告信号触发** | 近期的应激事件、暴露于自杀等 |

## 四、风险分层说明

### 4.1 C-SSRS 风险分层框架

| 风险等级 | C-SSRS指标 | 特征描述 |
|---------|-----------|---------|
| **低危** | 无自杀意念 | 仅有情绪问题，无自杀意念 |
| **低-中危** | 1级被动意念 | 有被动死亡意念，但无积极行动意图 |
| **中危** | 2-3级主动意念 | 有主动自杀想法，但无计划/准备/意图 |
| **高危** | 4级主动意念+计划 | 有具体计划，可能有或无准备 |
| **极高危** | 5级+准备行为/未遂/死亡 | 有计划并有准备行动，或已实施 |

### 4.2 风险分层决策表

| C-SSRS得分/维度 | 风险等级 | 建议行动 |
|---------------|---------|---------|
| 无意念、无行为 | **低危** | 常规随访；心理教育 |
| 1级（被动意念） | **低-中危** | 关注随访；增加接触频率；限制可及性 |
| 2-3级（主动意念，无计划） | **中危** | 每周随访；心理治疗；评估支持系统 |
| 4级（有计划，无准备） | **高危** | 每周2-3次随访；心理治疗；安全计划 |
| 5级（有计划+准备）/有行为 | **极高危** | 立即转介精神科；安全评估；考虑住院 |

## 五、安全计划模板（C-SSRS配套工具）

安全计划（Safety Plan）是 C-SSRS 评估后配合使用的危机应对工具：

| 步骤 | 内容 | 示例 |
|------|------|------|
| **Step 1** | 识别个人预警信号 | "当我感到绝望且无法入睡时" |
| **Step 2** | 使用内部应对策略 | "练习正念呼吸；给朋友打电话" |
| **Step 3** | 向家人朋友寻求支持 | "联系张三：138xxxx" |
| **Step 4** | 联系专业帮助 | "拨打12356热线；联系李医生" |
| **Step 5** | 减少可及性 | "将药物交给家人保管；家中不留利器" |
| **Step 6** | 使环境安全化 | "锁好门窗；远离危险物品" |

## 六、C-SSRS的优势

| 优势 | 说明 |
|------|------|
| **无需精神科背景** | 非专业人员也可使用，适合全科医生、护士、社区工作者 |
| **标准化程度高** | 有明确的问题脚本和评分标准，便于培训和质量控制 |
| **覆盖完整谱系** | 从被动意念到主动意念、计划、行为全覆盖 |
| **跨文化适用** | 已翻译为100+语言，跨文化效度良好 |
| **免费使用** | 非商业目的免费，推动了全球自杀风险评估标准化 |
| **FDA认可** | 是抗抑郁药临床试验的强制性评估工具 |
| **可追踪** | Lifetime/Recent 版本可追踪不同时间段的自杀风险变化 |
| **预测价值** | 多个前瞻性研究表明 C-SSRS 可预测未来自杀行为（风险比 2-4倍） |

### 7.1 推荐使用场景

| 场景 | 推荐使用的 C-SSRS 版本 |
|------|---------------------|
| **门诊快速筛查** | 筛选版（Screening Version）4-5题 |
