# C-SSRS等危机量表

## 用途
哥伦比亚自杀严重程度评定量表（C-SSRS）是最权威的自杀风险评估工具，包括：自杀意念（5个等级）、自杀行为（4种类型）、最大自杀风险评估。C-SSRS是自杀风险等级判定的重要依据。

C-SSRS、哥伦比亚、自杀意念、行为、风险评估、自杀未遂、致命性、保护因素

## 权威来源
Columbia University C-SSRS官方；Posner et al. (2011) C-SSRS信效度研究

## 文档描述
本文档详细介绍C-SSRS量表：1）自杀意念评估（5个严重程度等级：被动意念、主动意念、非特异性主动意念、特定计划、特定计划+意图）；2）自杀行为评估（4种：准备行为、尝试、中断尝试、实际尝试）；3）致命性评估；4）保护因素评估；5）风险等级综合判定（低/中/高）。本文裨对VIS4SRD系统的价值在于标准化自杀风险等级判定和危机程度评估。
