# 非自杀性自伤（NSSI）识别与干预

> 本文档介绍非自杀性自伤（Non-Suicidal Self-Injury, NSSI）的识别方法与干预策略。来源：WHO mhGAP、美国心理健康服务（MHA）、循证临床指南。

---

## 基本概念

### 定义

非自杀性自伤（NSSI）是指在没有明确自杀意图的情况下，故意对自己身体组织造成损伤的行为。

### 与自杀性自伤的区别

| 特征 | 非自杀性自伤（NSSI） | 自杀性自伤 |
|-----|-------------------|-----------|
| **意图** | 调节情绪、获得关注、惩罚自己 | 结束生命 |
| **结果期望** | 损伤但不死 | 死亡 |
| **常见行为** | 割伤、烧伤、撞击、撕扯皮肤 | 自缢、枪击、溺水 |
| **发生率** | 青春期约 15-20% | 相对较低 |
| **共病** | 边缘型人格障碍、进食障碍 | 抑郁症、物质滥用 |

### 常见表现形式

- **切割（Cutting）**：最常见，用刀片、玻璃等划伤皮肤
- **烧伤（Burns）**：用烟头、打火机等灼烧皮肤
- **撞击（Hitting）**：用手或物体击打自己
- **抓伤（Scratching）**：用力抓挠皮肤至出血
- **拔毛（Hair Pulling）**：强迫性拔除毛发（属于 TTM）
- **皮肤撕扯（Skin Picking）**：强迫性抠挖皮肤

---

## 流行病学

- **青少年群体**：NSSI 发生率约为 **13-23%**
- **大学生群体**：终身患病率约 **15-35%**
- **女性**：报告率约为男性的 **2-3 倍**（可能存在报告偏倚）
- **共病**：约 **60-70%** 的 NSSI 个体同时满足至少一种精神障碍标准

---

## 功能分析（Four-Function Model）

理解 NSSI 的心理功能有助于针对性干预：

### 1. 内在正强化（Intrapersonal Positive Reinforcement）

- 减少情绪痛苦（Emotional Regulation）
- 缓解紧张感（ Tension Reduction）
- 体验控制感

### 2. 内在负强化（Intrapersonal Negative Reinforcement）

- 停止解离状态
- 减轻麻木感
- 产生"真实感"

### 3. 外在正强化（Interpersonal Positive Reinforcement）

- 获得关注
- 获取帮助
- 引起他人同情

### 4. 外在负强化（Interpersonal Negative Reinforcement）

- 逃避责任或任务
- 回避社交情境
- 结束人际冲突

## 识别线索

### 直接线索

- 身上出现无法解释的伤口、疤痕或淤青
- 反复遮掩特定身体部位（长袖、绷带）
- 经常随身携带尖锐物品（刀片、针）

### 间接线索

- 情绪波动剧烈但无法用语言表达
- 自我价值感极低
- 存在完美主义倾向或极端自我要求
- 人际关系困难、经常感到被误解
- 冲动控制困难

### 行为表现

- 社交退缩但渴望连接
- 物质滥用增加
- 自我伤害行为有明显的"触发-行为-结果"模式

## 评估要点

### 评估量表

推荐使用 **Deliberate Self-Harm Inventory (DSHI)** 或 **Self-Injury Screening Tool (SITBI)**

### 关键评估问题

1. "您是出于什么目的伤害自己的？"
2. "这种行为通常在什么情况下发生？"
3. "伤害自己后有什么感受？"
4. "有没有尝试过替代方式来应对？"
5. "您是否曾因这些行为去急诊或接受治疗？"

### 功能评估框架

使用 **Functional Alternative Assessment** 评估 NSSI 的四大功能，以便选择对应的干预策略。

## 干预策略

### 1. 辩证行为疗法（DBT）

**DBT 是 NSSI 循证干预的金标准**，包含：

- **正念技能（Mindfulness）**：提高情绪觉察
- **痛苦耐受技能（Distress Tolerance）**：接受痛苦而不行动
- **情绪调节技能（Emotion Regulation）**：减少情绪脆弱性
- **人际效能技能（Interpersonal Effectiveness）**：改善人际交往

### 2. 安全计划（Safety Planning）

参照 **C-SSRS 安全计划模板**：
1. 识别个人预警信号
2. 列出内部应对策略
3. 列出可联系的家人朋友
4. 列出专业求助资源
5. 确保环境安全（移除尖锐物品）
6. 制定承诺声明

### 3. 认知行为疗法（CBT）

- 识别触发 NSSI 的自动思维
- 发展替代性应对策略
- 认知重构负性信念

### 4. 家庭治疗（针对青少年）

- 提高家长的识别和应对能力
- 改善家庭沟通模式
- 建立安全的家庭环境

### 5. 接纳与承诺疗法（ACT）

- 接纳痛苦情绪的存在
- 承诺采取价值导向行为
