# 高危信号识别指南

> 本文档系统介绍自杀风险的高危预警信号，包括言语、行为、环境三个维度。来源：WHO mhGAP 自杀预防指南、C-SSRS 评估框架、循证自杀预防研究。

---

## 高危信号概述

识别自杀风险的第一步是关注**高危信号（Warning Signs）**。根据 WHO 和美国自杀学会（AAS）的循证研究，约 **80%** 的自杀死亡者在死前数周至数月表现出可识别的预警信号。

---

## 一、言语信号（Verbal Warning Signs）

### 1.1 直接表达

- "我不想活了"
- "活着有什么意义"
- "我走了你们就轻松了"
- "我想死"
- "我受够了"

### 1.2 间接暗示

- "很快你们就不用再担心我了"
- "一切都会结束的"
- "我欠的债终于可以还清了"（比喻性表达）
- "没有我别人会过得更好"
- "我觉得自己是别人的负担"

### 1.3 关于死亡的深入讨论

- 频繁谈论死亡或自杀话题
- 研究自杀方法（网络搜索、书籍阅读）
- 谈论具体的自杀计划（而非模糊的意念）
- 撰写遗书或告别信

### 临床提示

> 直接表达自杀意念（如"我想死"）比间接暗示具有更高的风险预测价值。**具体化**（提及时间、地点、方式）的自杀计划比模糊意念风险更高。

---

## 二、行为信号（Behavioral Warning Signs）

### 2.1 近期重大负性生活事件

- 亲密关系破裂（分手、离婚）
- 重要他人去世
- 失业或财务危机
- 严重的法律或学业挫折
- 遭受暴力或虐待

### 2.2 个体行为变化

| 行为类型 | 具体表现 |
|---------|---------|
| **退缩行为** | 突然回避社交、远离朋友和家人 |
| **自我隔离** | 长时间独处，拒绝参与活动 |
| **情绪剧烈波动** | 从极度悲伤到异常平静（可能更危险） |
| **睡眠问题** | 严重失眠或嗜睡 |
| **饮食变化** | 食欲明显减退或暴饮暴食 |
| **物质滥用** | 酒精或药物使用增加 |
| **冲动行为** | 鲁莽驾驶、危险行为增加 |
| **赠送物品** | 将珍贵物品送给别人 |
| **整理事务** | 突然安排后事、清理债务 |

### 2.3 既往自杀史

- **最重要的风险预测因子之一**
- 有过自杀未遂史者风险是无自杀史者的 **6-8 倍**
- 近期自杀未遂（尤其是过去3个月内）是极高危信号

### 2.4 获取自杀手段

- 购买刀具、绳索
- 收集药物（安眠药、抗抑郁药等）
- 查询农药或其他致死物质
- 关注枪支相关信息

## 三、环境信号（Environmental Warning Signs）

### 3.1 社会支持丧失

- 家庭破裂、离婚
- 亲密朋友数量骤减
- 被社会团体排斥

### 3.2 持续性压力

- 长期失业
- 经济困境
- 法律纠纷
- 慢性疾病

### 3.3 丧失感

- 亲人死亡
- 宠物死亡
- 重要财产损失
- 社会身份丧失（退休、失业）

---

## 四、精神状态关联信号

### 4.1 抑郁症伴随信号

- 持续的情绪低落（>2周）
- 兴趣丧失（快感缺乏）
- 无望感（Hopelessness）—— **最强的预测因子之一**
- 反复出现死亡或自杀相关念头

### 4.2 双相情感障碍信号

- 躁狂/轻躁狂发作后突然转为抑郁
- 混合状态（同时存在抑郁和躁狂特征）风险极高

### 4.3 焦虑障碍信号

- 广泛性焦虑伴随惊恐发作
- 社交焦虑伴随回避行为

### 4.4 物质滥用信号

- 酒精依赖伴随抑郁
- 药物滥用降低抑制控制

## 五、风险分级框架

基于 **C-SSRS 评估框架**，可将风险分为三级：

### 高风险（High Risk）

满足以下任一条件：
- 有具体的自杀计划
- 近期有自杀未遂（<3个月）
- 目前处于急性精神病状态
- 有高危手段的可及性（如储存大量药物）
- 表达强烈的无望感

### 中风险（Moderate Risk）

满足以下条件：
- 存在自杀意念但无具体计划
- 有行为变化但无急性危险
- 有既往自杀史但近期稳定
- 有明确的压力源但有社会支持

### 低风险（Low Risk）

满足以下条件：
- 仅存在死亡相关想法但无具体意念
- 无计划、意图或既往史
- 有足够的社会支持
- 无重大精神障碍

## 六、临床识别要点

### 问询技巧

使用 **C-SSRS 筛选版** 核心问题：
1. "您是否曾希望自己已经死了，或者希望自己可以睡着然后不再醒来？"
2. "在过去一个月里，您是否曾有过自杀的想法？"
3. "您是否曾有过自杀的计划？"
4. "您是否曾有过自杀的尝试？"

### 非精神科医生的识别

WHO mhGAP 建议基层医护人员关注：
- 既往自杀未遂史
- 目前有抑郁或物质滥用
- 近期有重大负性生活事件
- 表现出无望感或社交退缩
- 拒绝接受治疗或随访
