# 自杀与自伤主题索引

## 用途
自杀与自伤是VIS4SRD系统的核心关注领域。本主题涵盖：1）自杀预防与教育（高危信号识别、WHO指南）；2）自伤与自残（NSSI识别与干预）；3）危机表达与手段（告别信号、高危手段认知）；4）求助与转介。本主题为VIS4SRD系统的风险评估和干预提供核心知识支持。

## 主题基本信息
- **主题名称**：自杀与自伤
- **主题代码**：suicide_self_harm
- **主题描述**：自杀预防、自伤行为识别与干预相关内容
- **所属分类**：WHO mhGAP核心关注领域
- **权威来源**：WHO Mental Health Gap Action Programme (mhGAP)

## 文档描述
本主题包含7个核心文档：自杀危害与认知（统计数据、风险因素）；高危信号识别指南（言语/行为/环境信号）；WHO_LIVE_LIFE自杀预防指南；自伤行为识别与干预（NSSI）；遗书与告别信号；工具与高危手段认知；何时求助与转介指南。关键词：高危信号、预警、自杀意念、遗书、自伤、NSSI、危机、求助、转介。

## 子主题列表
- 自杀预防与教育：基础知识与高危信号识别
- 自伤与自残：非自杀性自伤NSSI
- 危机表达与手段：告别信号与工具手段认知
- 求助与转介：转介流程与资源对接
