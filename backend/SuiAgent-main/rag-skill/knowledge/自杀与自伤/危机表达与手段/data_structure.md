# 危机表达与手段

## 用途
识别告别信号与高危手段认知，包括：遗书内容分析、告别语言识别、告别行为信号（突然赠送物品）、高危手段类型及工具可及性评估。正确识别危机表达是自杀预防的关键。

## 文件说明
- 遗书与告别信号.md - 告别信号识别、遗书内容分析
- 工具与高危手段认知.md - 高危手段认知、工具获取途径

## 关键词
遗书、告别信号、轻生、高危手段、工具获取、自杀方法、致命性、可及性、危机表达

## 权威来源
WHO自杀预防指南；危机干预研究；自杀行为心理学

## 文档描述
本文档分析危机表达与手段：1）遗书与告别信息分析（常见主题：绝望、愤怒、爱与告别）；2）告别言语识别（"这是我最后一次..."、"照顾好..."）；3）告别行为信号（突然赠送物品、清偿债务）；4）高危手段认知（缢首、药物、溺水等）；5）工具可及性与风险评估；6）限制工具获取的干预策略。本文裨对VIS4SRD系统的价值在于识别危机表达信号和评估手段可及性。
