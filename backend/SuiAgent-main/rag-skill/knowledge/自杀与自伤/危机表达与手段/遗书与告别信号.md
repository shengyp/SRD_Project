# 遗书与告别信号识别

> 本文档介绍自杀相关遗书、告别信号及语言模式的识别要点，用于高危个体识别。来源：循证自杀预防研究、WHO mhGAP 指南、C-SSRS 评估框架。

---

## 遗书概述

### 定义

遗书（Farewell Letter / Suicide Note）是自杀者在生前留下的文字材料，表达其结束生命的意图、对亲人的告别或对生活的绝望。

### 流行病学

- 约 **25-35%** 的自杀死亡者会留下遗书或类似文字
- 书面遗书比电子遗书（如社交媒体帖子）更常见
- 青少年比成年人更可能在社交媒体上留下告别内容

---

## 遗书的语言特征

### 常见的情绪表达

| 情绪类型 | 典型表达 |
|---------|---------|
| **绝望** | "一切都没有意义了"、"不会再有希望了" |
| **无助** | "我无能为力"、"没有人能帮我" |
| **自我厌恶** | "我是失败者"、"我不配活着" |
| **被遗弃感** | "所有人都抛弃了我"、"我是负担" |
| **分离意向** | "我要走了"、"我要离开了" |
| **爱与原谅** | "我爱你们"、"请原谅我"（告别特征） |
| **指令性内容** | "照顾好孩子"、"不要为我难过" |

### 遗书中的告别模式

以下是被研究者识别的常见告别模式：

1. **直接告别**：明确表达离别意向
2. **原谅请求**：请求他人原谅自己的行为
3. **财产安排**：交代后事、处理物品
4. **爱意表达**：表达对家人朋友的爱
5. **责备转移**：将责任归咎于他人或外部环境

### 告别信号 vs 普通日记

| 特征 | 告别信号 | 普通日记/表达 |
|-----|---------|-------------|
| 时间背景 | 与负性事件紧密相关 | 时间跨度较大 |
| 情绪强度 | 极度绝望、决定性语气 | 情绪波动但有起伏 |
| 反复出现 | 反复表达相似内容 | 情绪有正常波动 |
| 计划性 | 伴随具体安排 | 无具体实施计划 |
| 社交联系 | 主动切断或交代后事 | 维持正常社交 |

## 社交媒体上的告别信号

现代自杀预防需关注**网络告别**（Online Farewells）：

### 常见形式

- **社交媒体帖子**：微博、朋友圈、知乎等平台的告别性内容
- **即时通讯消息**：微信、QQ 等的告别性消息
- **网络日志**：博客、空间的告别性文章
- **网络搜索记录**：搜索自杀方法、遗书格式等内容

### 识别要点

- 内容中出现"最后"、"告别"、"再见"等关键词
- 表达对亲友的感谢和道别
- 赠送或分配个人物品
- 突然清理社交账号或更改密码
- 内容表达极端无望感（如"一切都是假的"）

### Emoji 表达关联

研究发现，自杀风险高的用户在社交媒体上可能使用以下 Emoji 模式：
- 🔪💉🔫（工具类）
- 💊（药物）
- ☠️💀（死亡相关）
- 😢😭😞（悲伤情绪）
- ⬇️📉🔒（下降/锁闭意象）

> **VIS4SRD Emoji 情绪模型**：基于微博、Reddit 等数据集训练的 Emoji 模型可识别上述风险模式。

## C-SSRS 中的告别信号评估

根据 **C-SSRS 评估框架**，以下问题帮助识别告别意图：

1. "这个人是否留下了遗书或类似文字？"
2. "这些文字中是否表达了离开或永别的意向？"
3. "是否有对亲友的告别或财产交代？"
4. "在发布告别内容后，是否尝试采取行动？"

---

## 识别后的干预措施

### 即时干预

1. **紧急评估**：确认个体当前位置和状态
2. **联系紧急服务**：必要时拨打 120/110
3. **保持联系**：持续与个体保持通讯
4. **寻找现实线索**：了解个体是否已获取自杀手段

### 安全计划

- 确保个体身边有人陪伴
- 移除环境中的高危物品
- 制定具体的求助计划
- 安排后续随访

### 心理支持

- 提供危机热线（全国心理援助热线：400-161-9995）
- 联系专业心理危机干预人员
- 必要时住院评估
