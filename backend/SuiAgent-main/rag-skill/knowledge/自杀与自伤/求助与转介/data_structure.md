# 求助与转介

## 用途
何时求助与转介流程指导，包括：识别需要专业帮助的信号、选择适当的求助渠道（社区/专科/急诊）、转介流程与资源对接。正确的求助和转介是自杀预防的关键保护因素。

## 文件说明
- 何时求助与转介指南.md - 转介流程、资源对接、求助时机完整指南

## 关键词
求助、转介、医疗资源对接、心理急救、危机热线、自杀未遂后转介、社区精神科、综合医院精神科

## 权威来源
国家卫生健康委员会；WHO mhGAP；Zero Suicides Initiative

## 文档描述
本文档指导求助与转介：1）识别求助信号（自伤行为、自杀意念、严重功能损害）；2）求助渠道选择（心理援助热线、社区心理服务、综合医院精神科、精神专科医院）；3）急诊转介指征（正在实施自杀行为、严重精神病性症状）；4）转介流程（信息传递、预约安排、随访确认）；5）持续支持与随访。本文裨对VIS4SRD系统的价值在于指导用户正确选择求助渠道和流程。
