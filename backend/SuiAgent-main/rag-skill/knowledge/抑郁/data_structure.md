# 抑郁主题索引

## 用途
抑郁症是自杀最重要的风险因素之一，约50%的自杀死亡者生前患有抑郁症。本主题涵盖：1）抑郁症状识别与评估；2）抑郁与自杀风险关系；3）治疗与药物；4）PHQ-9等量表使用。本主题为VIS4SRD系统的抑郁风险筛查提供循证支持。

## 主题基本信息
- **主题名称**：抑郁
- **主题代码**：depression
- **主题描述**：抑郁症相关知识、症状识别、治疗与自杀风险关联
- **所属分类**：《中国抑郁障碍防治指南2025版》
- **权威来源**：中华医学会精神医学分会，人民卫生出版社

## 文档描述
本主题包含6个核心文档：抑郁症状识别与评估（DSM-5/ICD-11诊断标准）、抑郁症识别与分类、抑郁与自杀风险关系、抑郁症治疗与药物、抑郁症自助指南、PHQ-9量表说明。关键词：抑郁、PHQ-9、快感缺失、绝望感、SSRIs、CBT、自杀意念。

- BDI（贝克抑郁量表）：严重程度评估
