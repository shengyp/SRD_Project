# 抑郁量表说明与解读

> 本文档介绍常用抑郁量表（PHQ-9、BDI、HAMD）的使用方法、评分标准和结果解读。来源：Pfizer官方指南、《中国抑郁障碍防治指南2025版》。

---

## PHQ-9（患者健康问卷-9）

### 基本信息

- **开发者**：Pfizer Inc.
- **题目数量**：9题
- **评估周期**：过去2周
- **施测时间**：2-5分钟
- **特点**：自评量表，免费使用，广泛用于初级保健

### 量表内容

在过去2周里，您有多少时间受以下问题困扰？

| 序号 | 问题 | 评分标准 |
|-----|------|---------|
| 1 | 做事时提不起劲或没有兴趣 | 0=没有 1=几天 2=一半以上 3=几乎每天 |
| 2 | 感到心情低落、沮丧或绝望 | 同上 |
| 3 | 入睡困难、睡眠不好或睡眠过多 | 同上 |
| 4 | 感觉疲倦或精力不足 | 同上 |
| 5 | 食欲不振或吃得太多 | 同上 |
| 6 | 觉得自己很糟糕，或让自己/家人失望 | 同上 |
| 7 | 对阅读报纸或看电视时的专注力感到困难 | 同上 |
| 8 | 说话或动作比平时缓慢，或相反（坐立不安） | 同上 |
| 9 | 有不如死掉或用某种方式伤害自己的念头 | 同上 |

**第9题为自杀意念筛查，是PHQ-9的核心关注项**

### 评分标准

| 总分 | 抑郁严重程度 | 建议处置 |
|-----|------------|---------|
| 0-4 | 无或极轻微 | 无需处理 |
| 5-9 | 轻度抑郁 | 观察、随访 |
| 10-14 | 中度抑郁 | 制定治疗计划，考虑药物治疗 |
| 15-19 | 中重度抑郁 | 药物治疗+心理治疗 |
| 20-27 | 重度抑郁 | 积极药物治疗+心理治疗，评估自杀风险 |

### 临床应用要点

- **初步筛查**：PHQ-2（仅前2题）可用于快速筛查
- **监测治疗效果**：定期重复施测
- **自杀风险**：第9题≥1分需进一步评估自杀风险
- **局限性**：不能替代临床诊断

## BDI-II（贝克抑郁量表第2版）

### 基本信息

- **开发者**：Aaron T. Beck
- **题目数量**：21题（SDS为20题）
- **评估周期**：过去2周（包括今天）
- **施测时间**：5-10分钟
- **特点**：他评/自评均可，敏感性和特异性高

### 量表内容（节选）

| 序号 | 内容领域 | 评分范围 |
|-----|---------|---------|
| 1 | 悲伤 | 0-3 |
| 2 | 悲观 | 0-3 |
| 3 | 失败感 | 0-3 |
| 4 | 快感缺失 | 0-3 |
| 5 | 自我厌恶 | 0-3 |
| 6 | 自我惩罚 | 0-3 |
| ... | ... | ... |
| 21 | 对性失去兴趣 | 0-3 |

### 评分标准

| 总分 | 抑郁严重程度 |
|-----|------------|
| 0-13 | 极轻微 |
| 14-19 | 轻度 |
| 20-28 | 中度 |
| 29-63 | 重度 |

## HAMD（汉密尔顿抑郁量表）

### 基本信息

- **开发者**：Max Hamilton
- **题目数量**：17项（HAMD-17）
- **评估周期**：过去1周
- **施测时间**：15-20分钟
- **特点**：他评量表，是临床试验的金标准

### 量表内容（主要项目）

| 类别 | 项目 |
|-----|------|
| **情感症状** | 抑郁情绪、有罪感、自杀 |
| **躯体症状** | 入睡困难、睡眠不深、早醒、食欲丧失、性欲减退 |
| **认知症状** | 阻滞、激越、自知力 |
| **妄想/幻觉** | 偏执、强迫、人格解体 |

### 评分标准

| 总分 | 抑郁严重程度 |
|-----|------------|
| <7 | 正常 |
| 7-17 | 可能有抑郁症 |
| 18-24 | 轻度-中度抑郁 |
| ≥25 | 重度抑郁 |

---

## 量表选择指南

| 场景 | 推荐量表 | 理由 |
|-----|---------|------|
| **初级保健筛查** | PHQ-2 → PHQ-9 | 快速、免费、简单 |
| **临床严重程度评估** | HAMD-17 | 金标准 |
| **自评监测** | PHQ-9 或 BDI-II | 可自行完成 |
| **自杀风险筛查** | PHQ-9第9题 → C-SSRS | 快速识别 |
| **流行病学调查** | PHQ-9 | 标准化、可比性强 |

---

## 联合使用建议

### PHQ-9 + C-SSRS

- PHQ-9 高分（第9题≥1分）→ 触发 C-SSRS 评估
- 综合评估自杀风险等级

### 量表复查频率

| 治疗阶段 | 建议复查频率 |
|---------|------------|
| 急性期（0-12周） | 每2-4周 |
| 巩固期（4-9月） | 每4-8周 |
| 维持期 | 每3-6月 |
