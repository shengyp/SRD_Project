# 抑郁量表说明

## 用途
抑郁量表使用指南与解读，主要包括PHQ-9（患者健康问卷-9）、BDI（贝克抑郁量表）、HAMD（汉密尔顿抑郁量表）的评分标准、阈值解释及临床应用。

## 文件说明
- 抑郁量表说明与解读.md - PHQ-9、BDI等量表使用说明完整指南

## 关键词
PHQ-9、BDI、HAMD、抑郁量表、评分标准、严重程度、自杀意念、临界值、筛查工具

## 权威来源
Pfizer PHQ-9官方指南；Beck AT BDI手册；《中国抑郁障碍防治指南2025版》

## 文档描述
本文档详细介绍抑郁筛查量表的使用：1）PHQ-9量表（9题，第9题评估自杀意念，5/10/15/20分为轻/中/重/极重度）；2）BDI贝克抑郁量表（21题，0-13/14-19/20-28/29-63为轻/中/重/极重度）；3）PHQ-9第9题解读（自杀意念单独评估的重要性）；4）量表组合使用建议。本文裨对VIS4SRD系统的价值在于标准化量表评分解读和风险判定。
