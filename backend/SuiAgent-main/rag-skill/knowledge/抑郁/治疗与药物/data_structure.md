# 治疗与药物

## 用途
抑郁症治疗方案与药物使用指南，包括SSRIs/SNRIs等一线抗抑郁药、CBT心理治疗、联合治疗方案及住院指征。循证治疗可将自杀风险降低约60%，规范治疗是自杀预防的关键环节。

## 文件说明
- 抑郁症治疗与药物.md - 药物治疗与心理治疗方案完整指南
- 抑郁症自助指南.txt - 患者自助指南

## 关键词
抗抑郁药、SSRIs、SNRIs、三环类、CBT、心理治疗、住院治疗、联合治疗、维持治疗、药物依从性

## 权威来源
《中国抑郁障碍防治指南2025版》；中华医学会精神医学分会；NICE指南；APA实践指南

## 文档描述
本文档系统介绍抑郁症的治疗方案：1）药物治疗（一线SSRIs：舍曲林、艾司西酞普兰等；SNRIs：文拉法辛等；二线三环类）；2）心理治疗（CBT、IPT、行为激活）；3）联合治疗方案及选择原则；4）住院治疗指征（严重自杀风险、功能丧失、共病）；5）维持治疗时长（首次发作6-12月，复发性2年+）；6）患者自助策略（睡眠管理、运动、社会支持）。本文裨对VIS4SRD系统的价值在于指导治疗建议和药物信息提供。
