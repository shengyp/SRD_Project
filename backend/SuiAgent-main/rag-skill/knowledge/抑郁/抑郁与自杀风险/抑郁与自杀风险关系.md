# 抑郁与自杀风险

> 本文档介绍抑郁症与自杀风险的关联机制、风险因素及综合评估框架。来源：《中国抑郁障碍防治指南（2025版）》、WHO mhGAP、C-SSRS。

---

## 抑郁与自杀的流行病学关联

### 核心数据

- 约 **40-60%** 的自杀死亡者生前患有抑郁症
- 抑郁症患者的自杀风险是一般人群的 **20倍**
- 约 **2/3** 的自杀死亡者曾因抑郁就诊，但多在非精神科
- 自杀是抑郁症最严重的**致死性结局**

### 风险比值

| 研究 | 标准化死亡比（SMR） |
|-----|------------------|
| 抑郁症（住院） | 20.4 |
| 双相障碍（躁狂期） | 15.1 |
| 物质滥用 | 6.7 |
| 精神分裂症 | 5.1 |
| 人格障碍 | 3.5 |

## 抑郁患者自杀风险增加的机制

### 1. 神经生物学因素

| 机制 | 说明 |
|-----|------|
| **5-HT系统 dysfunction** | 5-羟色胺水平降低与冲动攻击、自杀相关 |
| **HPA轴失调** | 皮质醇持续升高损害应激调节 |
| **BDNF下降** | 脑源性神经营养因子减少影响神经可塑性 |
| **炎症反应** | IL-6、TNF-α等炎症因子与抑郁自杀相关 |

### 2. 心理因素

- **无望感（Hopelessness）**：对未来的绝望是最强的自杀预测因子
- **认知僵化**：无法看到其他解决问题的途径
- **痛苦回避**：将自杀视为逃离无法承受的痛苦的方式
- **人际需求受挫**：累赘感知、被遗弃感

### 3. 社会环境因素

- 社会支持缺失
- 近期负性生活事件
- 经济困难
- 获取自杀手段的便利性

## 抑郁亚型与自杀风险

### 高风险亚型

| 亚型 | 自杀风险 | 特征 |
|-----|---------|------|
| **激越性抑郁** | 极高 | 极度焦虑、冲动、易激惹 |
| **迟滞性抑郁** | 中高 | 极度无助、淡漠、丧失动力 |
| **伴精神病性症状** | 极高 | 伴有妄想/幻觉（如罪恶妄想） |
| **双相抑郁** | 高 | 躁郁转换期风险最高 |
| **非典型抑郁** | 中 | 暴食、睡眠过多、铅样麻痹 |

### 自杀风险特征

```
高风险组合：
├── 严重抑郁 + 无望感 → 极高风险
├── 严重抑郁 + 既往自杀未遂史 → 极高风险
├── 严重抑郁 + 物质滥用 → 极高风险
├── 严重抑郁 + 急性应激 → 高风险
└── 严重抑郁 + 社会隔离 → 高风险
```

## 综合风险评估框架

### C-SSRS 自杀风险评估维度

| 维度 | 评估内容 | 抑郁患者关注点 |
|-----|---------|--------------|
| **自杀意念强度** | 频率、持续时间、可抗拒性 | 高频持久的意念风险高 |
| **自杀计划** | 具体性、时间性、方式 | 具体计划意味高风险 |
| **自杀手段** | 可及性、致死性 | 高致死性手段风险高 |
| **意向/筹备** | 是否有行动意向 | 筹备行为（买药）极高危 |
| **既往史** | 自杀未遂次数、严重程度 | 既往未遂是最强预测因子 |

### 自杀风险分层

| 风险等级 | 指标 | 建议处置 |
|---------|------|---------|
| **极高危** | 有计划+有手段+近期未遂+精神病性症状 | 立即住院；强制治疗 |
| **高危** | 主动意念+具体计划 OR 多次未遂 | 住院或密集随访（≤1次/周）|
| **中危** | 偶有意念+无计划 OR 1次未遂 | 门诊治疗（≤2次/周）+ 安全计划 |
| **低危** | 被动意念+无计划+无既往史 | 常规随访 + 心理教育 |

## 抑郁患者自杀的临床处理

### 急性期

1. **安全评估**：立即进行 C-SSRS 评估
2. **安全计划**：制定书面的、个体化的安全计划
3. **环境安全**：移除高危物品（药物、刀具等）
4. **家属参与**：确保有人陪伴和监督
5. **必要时住院**：保护性住院指征：
   - 严重自杀意念伴计划
   - 拒绝进食/饮水
   - 精神病性症状
   - 自伤行为无法控制

### 维持期

- **规范抗抑郁治疗**：SSRIs/SNRIs/安非他酮等
- **心理治疗**：CBT、D-CBT（针对自杀的 CBT）
- **锂盐**：有证据表明锂盐可降低自杀风险
- **密集随访**：出院后1周内随访，此后逐渐延长间隔
- **持续安全评估**：每次就诊时重新评估

### 共病处理

- **焦虑共病**：SSRIs + 抗焦虑药
- **物质滥用**：同时治疗物质使用障碍
- **边缘型人格**：DBT 为首选

## 心理自治区的"协作安全计划"

对于有自杀风险的抑郁患者，推荐使用**协作安全计划（Collaborative Safety Planning）**：

```
步骤1：识别个人预警信号
- 内在信号：反复哭泣、无法起床
- 外部信号：停止接电话、社交退缩

步骤2：列出内在应对策略
- 分散注意力：散步、听音乐
- 情绪表达：写日记、找人倾诉

步骤3：列出可联系的人
- 家人/朋友：___（电话：___）
- 热线：400-161-9995

步骤4：列出专业帮助途径
- 主治医生：___（电话：___）
- 急诊：___

步骤5：确保环境安全
- 将药物交给家属保管
- 移除家中尖锐物品

步骤6："我的承诺"
- 我承诺至少等待24小时再行动
- 我会活下去，因为___
```
