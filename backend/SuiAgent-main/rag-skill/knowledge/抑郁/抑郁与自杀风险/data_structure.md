# 抑郁与自杀风险

## 用途
抑郁与自杀的共病关系分析，包括：抑郁作为自杀最重要的风险因素、机制（绝望感、认知扭曲）、风险量化（约60%的自杀死亡者患有抑郁症）、共病问题及保护因素。

## 文档描述
本文档深入分析抑郁与自杀的共病关系：1）流行病学数据（60%自杀死亡者患抑郁症）；2）核心机制（绝望感是抑郁-自杀链的关键环节）；3）风险因素（既往自杀未遂、物质滥用、共病焦虑）；4）抑郁亚型与自杀风险；5）保护因素（社会支持、治疗依从性）。本文裨对VIS4SRD系统的价值在于量化抑郁-自杀风险关联、指导风险评估。
