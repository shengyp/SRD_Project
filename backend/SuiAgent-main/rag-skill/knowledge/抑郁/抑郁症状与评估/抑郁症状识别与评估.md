# 抑郁症状识别与评估

> 本文档系统介绍抑郁症的核心症状、诊断标准与临床评估方法。来源：《中国抑郁障碍防治指南（2025版）》、DSM-5-TR、ICD-11。

---

## 抑郁症概述

### 定义

抑郁症（Major Depressive Disorder, MDD）是一种以**持续的情绪低落、兴趣减退、认知功能损害**为核心特征的精神障碍，常伴有多种躯体症状，严重时可出现自杀意念和行为。

### 流行病学

- 全球约有 **3.8亿** 人患抑郁症（WHO 2023）
- 中国抑郁症终身患病率约 **6.9%**
- 女性患病率约为男性的 **2倍**
- 15-29岁人群中，抑郁症是导致残疾的首要原因
- 约 **60%** 的自杀死亡者生前患有抑郁症

## DSM-5-TR 诊断标准

根据 **DSM-5-TR**，抑郁发作的诊断需要满足以下条件：

### A 组症状（核心症状）- 至少满足5项，且必须包括1或2

| 序号 | 症状 | 说明 |
|-----|------|------|
| 1 | **情绪低落** | 感到悲伤、空虚或无望（儿童/青少年可为易激惹） |
| 2 | **兴趣减退/快感缺失** | 对几乎所有活动丧失兴趣或愉悦感 |
| 3 | **体重/食欲变化** | 显著体重减轻/增加，或食欲减退/增加 |
| 4 | **睡眠障碍** | 失眠（入睡困难、中途醒来）或嗜睡 |
| 5 | **精神运动性改变** | 激越或迟滞（他人可观察到） |
| 6 | **疲劳感** | 每天感到疲倦或精力不足 |
| 7 | **无价值感/过度自责** | 自我评价过低或不当的内疚感 |
| 8 | **注意力/决策困难** | 思考能力减退，犹豫不决 |
| 9 | **死亡/自杀相关想法** | 反复出现死亡念头，自杀意念或行为 |

### B 组要求

- 症状持续时间：**至少2周**
- 造成**临床显著痛苦**或**社会功能损害**
- 排除其他原因（物质/疾病/丧亲）

### C 组排除

- 从未出现躁狂/轻躁狂发作（否则诊断为双相障碍）

## ICD-11 分类体系

**ICD-11（2022年实施）**对抑郁症的分类：

| 分类 | 代码 | 说明 |
|-----|------|------|
| 单次发作抑郁障碍 | 6A40 | 首次或孤立发作 |
| 复发性抑郁障碍 | 6A41 | 两次或以上发作 |
| 混合性焦虑抑郁障碍 | 6A43 | 焦虑和抑郁症状同时存在但不满足各自诊断 |
| 继发性抑郁障碍 | 6A44 | 由其他疾病或物质引起 |

### 严重程度分级

| 严重程度 | 核心症状数 | 功能损害 | 自杀风险 |
|---------|-----------|---------|---------|
| **轻度** | 4-5个 | 轻度困难 | 低-中 |
| **中度** | 6-7个 | 中度困难 | 中-高 |
| **重度** | ≥8个 | 严重困难 | 高 |

## 核心症状详解

### 1. 情绪低落（Crying / Dysphoria）

- 感到"空虚"、"绝望"、"悲惨"
- 情绪在一天内有波动（通常早晨最重）
- 可能出现无明显诱因的哭泣
- 患者可能否认悲伤，但表现为情感平淡（Affect）

### 2. 快感缺失（Anhedonia）

**快感缺失是抑郁症最核心的症状之一**，定义为：

- 对曾经喜欢的活动丧失兴趣
- 无法体验愉悦感（Pleasure）
- 性快感缺失常见
- 可能表现为社交退缩

### 3. 认知症状（Cognitive Symptoms）

| 症状 | 表现 |
|-----|------|
| **注意力减退** | 难以集中、阅读困难、丢三落四 |
| **决策困难** | 犹豫不决、小事无法决定 |
| **记忆障碍** | 近记忆受损（抑郁症假性痴呆） |
| **无望感** | 对未来持消极预期（最强自杀预测因子） |
| **认知扭曲** | 非黑即白、以偏概全、情绪推理 |

### 4. 躯体症状（Somatic Symptoms）

- **睡眠障碍**：早醒（最特征性）、入睡困难、中段失眠
- **食欲/体重变化**：约50%患者出现体重下降
- **精神运动性改变**：
  - 激越型：坐立不安、踱步、绞手
  - 迟滞型：言语减少、动作缓慢、面具脸
- **疲劳/精力减退**：持续感到疲倦
- **躯体不适**：头痛、胃肠不适、心悸（需排除躯体疾病）

### 5. 自杀相关症状（Suicidality）

> **这是抑郁症最危险的症状，需要始终评估**

- **被动意念**："活着没意思"但不计划行动
- **主动意念**：有结束生命的想法
- **意向**：有采取行动的意图
- **计划**：制定具体计划
- **行为**：准备行为（如买药）或未遂/死亡

**PHQ-9 第9题是筛查自杀意念的标准工具**

## 临床评估要点

### 评估框架

| 维度 | 评估内容 |
|-----|---------|
| **病史** | 发作次数、病程、诱因、缓解期 |
| **症状** | 9个症状域逐一评估 |
| **功能** | 工作、社交、生活自理能力 |
| **风险** | 自杀意念、计划、手段、既往史 |
| **共病** | 焦虑、物质滥用、人格障碍 |
| **资源** | 社会支持、家庭环境 |

### 评估量表

| 量表 | 用途 | 优点 |
|-----|------|------|
| **PHQ-9** | 初筛+严重程度 | 快速、免费、自评 |
| **BDI-II** | 严重程度评估 | 敏感性高 |
| **HAMD-17** | 临床评估金标准 | 他评、专业 |
| **PHQ-15** | 躯体症状筛查 | 与PHQ-9配套 |

### 鉴别诊断

- **双相障碍**：需询问躁狂/轻躁狂史
- **破坏性心境失调障碍**（儿童）
- **持续性抑郁障碍（恶劣心境）**：症状较轻但持续≥2年
- **甲状腺功能减退**：可表现为抑郁症状
- **药物/物质所致**：排除用药史

## 特殊人群的抑郁表现

### 老年人

- 躯体主诉更突出
- 认知功能损害明显
- "隐匿性抑郁"：表现为各种不适
- 丧亲后抑郁风险增高

### 青少年

- 易激惹可能代替悲伤
- 学业/社交功能下降
- 退行行为（发脾气、依赖）
- 躯体症状（头痛、腹痛）
- 自伤行为（NSSI）常见

### 孕产妇

- 产后抑郁：产后4周内发病
- 围产期抑郁：孕期及产后1年
- 需评估对胎儿/婴儿的照护能力
