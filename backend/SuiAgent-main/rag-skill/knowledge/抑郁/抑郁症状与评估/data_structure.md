# 抑郁症状与评估

## 用途
抑郁症核心症状识别与评估方法，基于DSM-5/ICD-11诊断标准。包括：核心症状（情绪低落、兴趣减退、快感缺失、睡眠/食欲障碍）、附加症状（疲乏、自我价值感降低、自杀意念等）、严重程度分级及鉴别诊断。

## 文档描述
本文档系统介绍抑郁症的症状识别与评估：1）DSM-5诊断标准（2周内至少5项症状，包括核心症状情绪低落或兴趣减退）；2）ICD-11分类（单次发作性抑郁障碍、复发性抑郁障碍、恶劣心境）；3）严重程度分级（轻度/中度/重度）；4）鉴别诊断（双相抑郁、继发性抑郁、丧亲相关抑郁）；5）常见共病（焦虑障碍、物质使用障碍、人格障碍）。本文裨对VIS4SRD系统的价值在于指导抑郁症状识别和PHQ-9量表结果解读。
