# 情绪识别与表达

## 用途
情绪识别与表达能力是情绪智力的基础，包括情绪觉察、命名、区分及表达技巧。述情障碍（情绪识别困难）是自杀风险的独立预测因子。本文档介绍DBT情绪觉察技能、情绪粒度概念及TAS-20述情障碍评估。

## 权威来源
DBT（Dialectical Behavior Therapy）官方指南；Barrett LF 情绪粒度理论；Nemiah JC 述情障碍研究

## 文档描述
本文档系统介绍情绪识别与表达的理论与技能：1）情绪粒度概念及临床意义；2）述情障碍定义、TAS-20评估及与自杀风险关系；3）DBT情绪觉察技能（STOP技能）；4）情绪词汇表按效价分类。本文档对VIS4SRD系统的价值在于识别低情绪粒度风险信号、辅助RAG对话引导用户命名情绪、提供情绪标签数据。
