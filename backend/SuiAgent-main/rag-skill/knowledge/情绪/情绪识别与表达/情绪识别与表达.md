# 情绪识别与表达

> 来源：DBT（Dialectical Behavior Therapy）官方指南；Barrett LF 等情绪理论研究；Nemiah JC 述情障碍研究

---

## 一、情绪识别的定义

情绪识别（Emotion Recognition）是指个体对自身或他人情绪状态的觉察、区分与命名能力。它是情绪智力的基础，也是情绪调节的起点。

研究表明，**情绪识别困难**与多种心理健康问题密切相关，包括抑郁症、焦虑障碍、人格障碍以及自杀行为。准确识别自身情绪的人，更有可能采取适应性情绪调节策略。

---

## 二、情绪粒度（Emotional Granularity）

### 2.1 概念定义

情绪粒度（Emotional Granularity, EG）由 Barrett 教授（2004）提出，指个体在经验和使用情绪词汇时精细化程度的个体差异。

- **高情绪粒度**：能够用丰富、具体的词汇区分细微情绪差异（如"挫败感""失望""无奈"）
- **低情绪粒度**：倾向于使用笼统词汇描述情绪（如"难受""不好"）

### 2.2 临床意义

| 维度 | 高情绪粒度 | 低情绪粒度 |
|------|-----------|-----------|
| 情绪区分能力 | 强 | 弱 |
| 情绪调节效果 | 更好 | 更差 |
| 抑郁风险 | 较低 | 较高 |
| 自杀风险 | 较低 | 较高 |

### 2.3 提高情绪粒度的方法

1. **情绪词汇学习**：扩充个人情绪词汇表
2. **情绪日记**：每天记录具体情绪及触发事件
3. **正念觉察**：练习在情绪产生时暂停并命名
4. **认知重评**：区分情绪产生的原因与结果

## 三、述情障碍（Alexithymia）

### 3.1 定义

述情障碍（Alexithymia），字面意为"没有情绪词汇"（no words for emotion），是一种以情绪识别和表达困难为核心特征的心理现象。1972年由 Sifneos 命名。

> Nemiah JC, Sifneos PE. Psychosomatic research: a trend in psychiatry. Psychother Psychosom. 1970.

### 3.2 主要特征

| 特征维度 | 具体表现 |
|---------|---------|
| 识别情绪困难 | 难以区分不同情绪（如愤怒与焦虑） |
| 描述情绪困难 | 无法用语言表达内心感受 |
| 外向性思维 | 关注外部事件而非内在感受 |
| 缺乏想象力 | 对情感体验缺乏想象性加工 |

### 3.3 评估工具：TAS-20（多伦多述情障碍量表）

TAS-20 是最常用的述情障碍自评量表，共 20 题，3 个维度：

- **因子 I：识别情感困难**（7题）
- **因子 II：描述情感困难**（5题）
- **因子 III：外向性思维**（8题）

评分标准：1（完全不同意）~ 5（完全同意），总分≥61分提示存在述情障碍倾向。

### 3.4 述情障碍与自杀风险

述情障碍已被确定为自杀行为的独立风险因素。机制可能包括：

- 无法识别和命名痛苦情绪，导致情绪负荷累积
- 情绪调节策略匮乏
- 寻求帮助的能力受限
- 社交功能受损

## 四、情绪觉察的重要性

情绪觉察（Emotional Awareness）是 DBT 的核心技能之一，指有意识地注意到当前情绪状态的能力。

### 4.1 情绪觉察的作用

1. **识别触发因素**：了解哪些情境会引发特定情绪
2. **早期预警**：在情绪失控前采取行动
3. **元认知能力**：意识到自己在"经历情绪"而非"被情绪淹没"
4. **决策改善**：基于清晰的情绪信息做出更好的决定

### 4.2 DBT "STOP" 技能（情绪危机时的觉察技术）

| 步骤 | 操作 | 说明 |
|------|------|------|
| **S** | Stop | 暂停正在做的事 |
| **T** | Take a step back | 后退一步 |
| **O** | Observe | 观察发生了什么，身体感受是什么 |
| **P** | Proceed mindfully | 有意识地继续行动 |

## 五、情绪词汇表（按效价分类）

### 5.1 正向情绪词汇（效价 Positive）

| 强度 | 情绪词汇 |
|------|---------|
| 高强度愉悦 | 狂喜、欣喜若狂、兴高采烈、心花怒放 |
| 中强度愉悦 | 快乐、开心、愉快、满足、幸福 |
| 低强度愉悦 | 平静、放松、安宁、舒适、惬意 |
| 混合正向 | 期待、兴奋、感动、自豪、感激、欣慰 |

### 5.2 负向情绪词汇（效价 Negative）

| 类别 | 情绪词汇 |
|------|---------|
| **焦虑类** | 焦虑、担忧、紧张、不安、恐惧、恐慌、惊恐 |
| **抑郁类** | 悲伤、沮丧、绝望、失落、抑郁、哀伤、沮丧、忧郁 |
| **愤怒类** | 愤怒、生气、恼怒、烦躁、怨恨、敌意、暴怒 |
| **内疚类** | 内疚、愧疚、自责、羞耻、尴尬、懊悔 |
| **恐惧类** | 恐惧、害怕、担忧、惊恐、惊慌、胆怯 |
| **孤独类** | 孤独、寂寞、空虚、无助、被遗弃感 |
| **复杂情绪** | 矛盾、纠结、无力感、无望、无价值感 |
