# 情绪

## 用途
情绪主题概述，包括情绪识别与表达、情绪调节、负面情绪与风险三大子主题。情绪问题是抑郁症、焦虑障碍的核心症状，也是自杀风险的重要预测因子。

## 文件说明
- 情绪识别与表达/ - 情绪觉察、命名、述情障碍评估
- 情绪调节/ - DBT/CBT循证调节方法
- 负面情绪与风险/ - 负面情绪类型与风险关系

## 关键词
情绪、情绪智力、情绪识别、情绪调节、负面情绪、述情障碍、DBT技能、心理韧性

## 权威来源
DBT官方指南；Gross JJ情绪调节研究；Barrett LF情绪理论；WHO mhGAP

## 文档描述
情绪主题知识库概述，收录情绪识别与表达、情绪调节、负面情绪与风险三大领域内容。情绪问题是心理健康的核心维度，与自杀风险密切相关。本知识库基于DBT、CBT等循证疗法，提供系统的情绪管理理论与技能指南。
