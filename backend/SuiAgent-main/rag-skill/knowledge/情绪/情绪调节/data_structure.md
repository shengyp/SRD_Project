# 情绪调节

## 用途
DBT/CBT循证情绪调节方法，包括Gross情绪调节过程模型、DBT四大技能模块（正念、痛苦耐受、情绪调节、人际效能）、CBT认知重构技术及正念干预。情绪调节困难是自杀行为的独立风险因素。

DBT官方指南（Linehan MM）；Gross JJ情绪调节过程模型；CBT循证研究；Gratz & Roemer DERS量表

## 文档描述
本文档系统介绍循证情绪调节方法：1）Gross情绪调节过程五阶段模型；2）DBT四大技能模块详解（正念、痛苦耐受、情绪调节、人际效能）；3）CBT认知重构四步法及常见认知扭曲类型；4）正念练习技术（呼吸觉察、身体扫描、RAIN技术）。本文档对VIS4SRD系统的价值在于为情绪激动用户提供DBT技能引导、为RAG检索提供情绪调节知识、辅助DERS量表解读。
