# 情绪调节

> 来源：DBT（Dialectical Behavior Therapy）官方指南；Gross JJ 情绪调节过程模型；CBT（Cognitive Behavioral Therapy）认知重构技术；DBT循证研究系统综述

---

## 一、情绪调节的定义与重要性

### 1.1 核心定义

情绪调节（Emotion Regulation）是指个体影响自身情绪的类型、发生时间、体验方式和表达方式的能力和过程。

> Gross JJ. (1998). The emerging field of emotion regulation. Review of General Psychology.

### 1.2 为什么情绪调节重要？

| 维度 | 具体表现 |
|------|---------|
| 心理健康 | 良好的情绪调节是心理韧性的核心 |
| 社会功能 | 情绪调节能力影响人际关系质量 |
| 身体健康 | 长期情绪失调与心血管疾病、免疫功能相关 |
| 自杀风险 | 情绪调节困难是自杀行为的独立风险因素 |

**情绪调节困难量表（DERS）**（Gratz & Roemer, 2004）的研究表明，在6个维度上存在调节困难的人群，自杀风险显著升高：

| DERS 维度 | 定义 | 高风险表现 |
|-----------|------|-----------|
| 非接受性情绪反应 | 对负面情绪的负性反应 | "我不应该有这种感受" |
| 目标导向行为困难 | 完成任务的能力受损 | 负面情绪下无法专注工作 |
| 冲动控制困难 | 情绪驱动的冲动行为 | 情绪失控时做出伤害性行为 |
| 情绪觉察不足 | 对情绪的元认知能力差 | "我为什么难受？" |
| 情绪调节策略有限 | 缺乏适应性调节策略 | 只用酒精/逃避来应对 |
| 情绪清晰度不足 | 难以区分不同情绪 | 所有难受都叫"难过" |

## 二、情绪调节过程模型（Gross, 1998/2014）

Gross 提出的情绪调节过程模型（Process Model of Emotion Regulation）将情绪调节策略按时间阶段分为5类：

```
情绪产生过程：
情境 → 注意 → 评估 → 反应倾向 → 行为表达
        ↑       ↑       ↑        ↑
     选择性   认知    应对    调制
     注意     重评    聚焦    反应
```

### 2.1 各阶段调节策略

| 阶段 | 策略名称 | 具体方法 | 适应性 |
|------|---------|---------|-------|
| **情境选择** | 接近/回避情境 | 远离压力源或接近支持资源 | 中等 |
| **情境修正** | 改变情境 | 解决问题、协商、寻求帮助 | 高 |
| **注意分配** | 转移/集中注意 | 正念觉察、分散注意力 | 中等 |
| **认知重评** | 改变情绪意义 | 换个角度看问题、积极重构 | **高** |
| **反应调节** | 调制行为反应 | 行为抑制、放松训练、物质使用 | 变化大 |

### 2.2 适应性与非适应性策略对比

| 适应性好 | 适应性差 |
|---------|---------|
| 认知重评（换角度看问题） | 表达抑制（压抑情绪表达） |
| 问题解决 | 回避/逃避 |
| 寻求社会支持 | 物质使用（酒精、药物） |
| 正念觉察 | 反刍思维（反复纠结） |
| 接受情绪 | 情绪发泄（攻击性） |

> 研究发现：长期使用表达抑制策略者幸福感更低、社交关系更差；而认知重评与更好的心理健康相关。

## 三、DBT 四大技能模块

DBT（Dialectical Behavior Therapy，辩证行为疗法）由 Marsha Linehan 创建，是目前证据最充分的情绪调节干预方法之一。

DBT 的四大技能模块：

### 3.1 正念（Mindfulness）

**核心理念**：活在当下，不评判地觉察当下体验。

| DBT 正念技能 | 说明 |
|------------|------|
| "是什么"技能（Observe） | 单纯觉察感受、想法、感官体验 |
| "是什么"技能（Describe） | 用词语描述观察到的事物 |
| "如何做"技能（One-mindful） | 一次只做一件事，全身心投入 |
| "如何做"技能（Non-judgmental） | 不评判好坏对错，只看事实 |

### 3.2 痛苦耐受（Distress Tolerance）

**核心理念**：接纳无法改变的事实，在痛苦中生存而不被痛苦控制。

| 技能名称 | 具体做法 |
|---------|---------|
| TIPP（降阶技术） | 体温调节、剧烈运动、呼吸调整、渐进式肌肉放松 |
| 分心技术（PLEASE） | 远离（Leave）、积极活动（Activities）、人际交流（People）、自我安慰（Imagery）、其他感觉（Other senses）、环境改变（Environment） |
| 自我安抚（Sensory） | 用五感（看、听、触、闻、尝）安抚自己 |
| 接纳（Radical Acceptance） | 全面接纳现实，不评判、不抵抗 |

### 3.3 情绪调节（Emotion Regulation）

**核心理念**：理解情绪的功能，减少情绪脆弱性，增加正向情绪体验。

| 技能名称 | 具体做法 |
|---------|---------|
| 识别和命名情绪 | 用情绪词汇表精确区分和命名情绪 |
| 核查情绪事实 | 什么触发了这个情绪？身体有什么反应？情绪有多强烈？ |
| 反向行动（Check the Facts） | 评估情绪反应是否与现实匹配 |
| 情绪暴露（Emotion Exposure） | 面对恐惧情绪，不回避，逐渐降低敏感度 |
| 减少情绪脆弱性 | 增加正向情绪体验、减少"情绪毒素" |

### 3.4 人际效能（Interpersonal Effectiveness）

**核心理念**：在人际互动中有效表达需求，同时保持自尊和关系。

| 技能名称 | 说明 |
|---------|------|
| DEAR MAN | 描述（Describe）、表达（Express）、强化（Assert）、强化（Reinforce）、保持（Maintain）、表现（Appear）、协商（Negotiate） |
| GIVE | 和善（Gentle）、感兴趣（Interested）、验证（Validate）、 Easy manner（轻松姿态） |
| FAST | 公平（Fair）、不道歉（no Apologies）、守住立场（Stick to values）、真相（Truthful） |

## 四、CBT 认知重构技术

认知行为疗法（CBT）通过识别和改变适应不良的思维模式来改善情绪。

### 4.1 核心概念

| CBT 概念 | 定义 |
|---------|------|
| 自动思维 | 特定情境下自发涌现的想法，通常快速且无意识 |
| 中间信念 | 介于深层核心信念与自动思维之间的规则/态度 |
| 核心信念 | 关于自我、他人、世界的最根本的认知图式 |
| 认知扭曲 | 系统性的思维偏差 |

### 4.2 常见认知扭曲类型

| 类型 | 定义 | 例子 |
|------|------|------|
| 非黑即白思维 | 用两个极端评价事物，忽略中间地带 | "如果做不到完美，我就是失败者" |
| 灾难化 | 高估负面结果的可能性和严重性 | "我一定会出事" |
| 读心术 | 认定自己知道别人在想什么 | "他肯定觉得我很糟糕" |
| 情绪推理 | 根据情绪感受推断现实 | "我感到害怕，所以一定很危险" |
| 过度概括 | 从单一负面事件得出宽泛的负面结论 | "一次失败意味着我永远失败" |
| 选择性注意 | 过度关注负面细节，忽略正面证据 | 只记得批评，忽略称赞 |
| 贴标签 | 给自己或他人贴上固定标签 | "我就是个失败者" |
| 个人化 | 将外部事件不恰当地归因于自己 | "别人不高兴一定是我的错" |

### 4.3 认知重构四步法

```
Step 1: 识别自动思维
    ↓ "我在想什么？"
Step 2: 识别认知扭曲
    ↓ "这是哪种认知扭曲？"
Step 3: 生成替代思维
    ↓ "有什么更平衡的想法？"
Step 4: 评估替代思维
    "这个替代想法有多真实？"
```

## 五、正念情绪调节

正念（Mindfulness）是一种以开放、接受、不评判的态度，有意识地关注当下体验的心理状态。

### 5.1 正念的核心机制

| 机制 | 作用 |
|------|------|
| 去中心化（De-centering） | 从"沉浸于情绪"转为"观察情绪"，减少情绪融合 |
| 元认知觉察 | 意识到"我在想"与"我的想法不是现实" |
| 开放性接纳 | 允许情绪存在，不评判、不抗拒 |
| 注意力调节 | 将注意力从反刍思维转向当下体验 |

### 5.2 正念练习技术

| 练习 | 时长 | 核心内容 |
|------|------|---------|
| 呼吸觉察 | 5-10分钟 | 专注呼吸，当走神时温柔带回 |
| 身体扫描 | 10-20分钟 | 从头到脚依次觉察身体各部位感受 |
| 三步正念空间 | 3分钟 | 停下→觉察身体/情绪→选择行动 |
| RAIN 技术 | 5-10分钟 | Recognize（识别）→Allow（允许）→Investigate（探究）→Nurture（培育） |

## 六、循证情绪调节干预的系统综述结论

### 6.1 主要循证疗法的证据等级

| 疗法 | 证据等级 | 适用范围 | 推荐级别 |
|------|---------|---------|---------|
| **DBT** | ★★★★★（强） | BPD、重复自伤、自杀行为 | 一线推荐 |
| **CBT** | ★★★★★（强） | 抑郁、焦虑、愤怒管理 | 一线推荐 |
| **ACT（接受承诺疗法）** | ★★★★（较强） | 慢性疼痛、焦虑、抑郁 | 推荐 |
| **MBCT（正念认知疗法）** | ★★★★（较强） | 抑郁复发预防、情绪调节 | 推荐 |
| **情绪聚焦疗法（EFT）** | ★★★（中等） | 情绪识别与表达 | 推荐 |

### 6.2 系统综述主要结论（近年研究）

| 研究 | 主要结论 |
|------|---------|
| **Linehan et al. (2021) RCT** | DBT 在减少自杀行为方面优于对照组（TAU），NNT=4 |
| **Hofmann et al. (2022) Meta分析** | CBT 对情绪障碍有效，效应量 d=0.75（焦虑/抑郁） |
| **Kuyken et al. (2016) BMJ** | MBCT 减少抑郁复发风险 43%（已服药者） |
| **Sloan et al. (2017) Review** | 正念干预显著改善情绪调节困难（d=0.52） |
| **Harvey et al. (2018) Cochrane** | CBT-I（失眠认知行为疗法）对失眠有效，优于药物长期使用 |

### 6.3 情绪调节干预的核心原则

1. **个体化**：根据患者的具体情绪问题类型和严重程度选择干预方法
2. **技能化**：教授具体可操作的调节技能，而非仅提供理论
3. **练习导向**：情绪调节是技能，需要反复练习才能熟练
4. **综合干预**：DBT+CBT+正念的综合方法优于单一方法
5. **长期支持**：情绪调节能力培养需要持续的支持和随访
