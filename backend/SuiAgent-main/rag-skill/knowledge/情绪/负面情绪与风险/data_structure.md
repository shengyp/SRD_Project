# 负面情绪与风险

## 用途
负面情绪（焦虑、抑郁、愤怒、恐惧等）与心理健康风险的关系分析。强烈、持续或无法调节的负面情绪是自杀风险的重要预测因子。本文档介绍主要负面情绪类型、情绪风暴概念、心理韧性培养及风险保护因素。

## 权威来源
WHO Mental Health Gap Action Programme (mhGAP)；《中国抑郁障碍防治指南（2025版）》；Kessler RC 心理流行病学研究

## 文档描述
本文档系统分析负面情绪与心理健康风险：1）主要负面情绪类型（焦虑、抑郁、愤怒、恐惧、羞耻、内疚、孤独）定义与特征；2）情绪风暴概念及应对策略；3）负面情绪与自杀风险的定量关系研究；4）心理韧性培养方法；5）风险因素与保护因素分析。本文档对VIS4SRD系统的价值在于识别高风险负面情绪模式、辅助风险评估、提供心理韧性提升建议。
