# 心理援助热线与即时求助指南

> 本文档介绍中国心理援助热线体系及即时求助资源的使用指南。来源：国家卫生健康委员会《心理援助热线技术指南（试行）》（2024年）、《关于应用"12356"全国统一心理援助热线电话号码的通知》（2024年）。

---

## 全国心理援助热线体系

### 全国统一热线：12356

根据 **国家卫生健康委员会2024年通知**，全国统一心理援助热线号码为 **12356**。

**建设标准**：
- 每个设区的市至少开通 **1条** 心理援助热线
- 每条热线至少设置 **2个坐席**
- 每个坐席空间不小于 **4平方米**
- 每日提供不少于 **18小时** 心理援助服务

**服务时间**：截至2024年底已接通电话 **70余万通**，成功实施危机干预 **近万起**

### 核心热线资源

| 热线名称 | 号码 | 服务时间 | 主管单位 |
|---------|------|---------|---------|
| 全国统一心理援助热线 | **12356** | 每日≥18小时 | 国家卫健委 |
| 全国心理援助热线 | **400-161-9995** | 24小时 | 国家认证 |
| 北京心理危机研究与干预中心 | 010-82951332 | 24小时 | 北京回龙观医院 |

### 服务内容

根据 **《心理援助热线技术指南（试行）》**，热线提供四类核心服务：

| 服务类型 | 说明 |
|---------|------|
| **心理健康教育** | 普及心理健康知识，提高公众心理素养 |
| **心理咨询和心理疏导** | 提供情绪疏导、压力缓解、认知调整等专业支持 |
| **心理危机干预** | 对处于危机状态的来电者实施即时干预 |
| **自杀风险评估和干预** | 识别高危来电者，启动危机干预程序 |

## 热线咨询流程

### 标准接听流程

```
来电接入
    ↓
第1步：安全确认
  - 确认来电者当前位置
  - 评估是否有生命危险
  - 如有紧急危险，立即指导拨打120/110
    ↓
第2步：建立连接
  - 表达理解和接纳
  - 使用开放式问题了解情况
  - 评估危机状态（C-SSRS框架）
    ↓
第3步：风险评估
  - 自杀意念类型和强度
  - 是否有具体计划
  - 可及的手段和致死性
  - 既往自杀史
    ↓
第4步：即时干预
  - 制定安全计划
  - 联系可用的社会支持
  - 如需要，安排即时转介
    ↓
第5步：后续跟进
  - 确认来电者是否安全
  - 制定后续求助计划
  - 如需要，主动回拨跟进
```

## 即时求助指南

### 什么情况下应立即拨打热线

| 情况 | 紧迫程度 |
|-----|---------|
| 正在计划或已经实施自杀 | 🔴 立即拨打 |
| 有具体的自杀计划（时间/地点/方式） | 🔴 立即拨打 |
| 近期有自杀未遂 | 🔴 立即拨打 |
| 反复出现"不想活了"的想法 | 🟠 尽快拨打 |
| 严重的抑郁/焦虑且无法应对 | 🟠 尽快拨打 |
| 遭受重大创伤事件 | 🟡 当天拨打 |
| 长期心理痛苦但无紧急危险 | 🟢 常规咨询 |

### 拨打热线前准备

- 找一个**安全、私密**的环境
- 如果有自伤工具，准备好后**暂时移开**
- 如果有药物，准备好药品名称和剂量信息
- 如有既往病史，准备好相关信息
- 准备好一个可以陪伴你的家人/朋友的联系方式

### 如何有效利用热线

**热线咨询员会询问的内容**：
- 您的基本情况（年龄、性别、职业）
- 目前面临的主要困难
- 自杀想法的频率、强度、持续时间
- 是否有过往的自伤/自杀史
- 目前的社会支持情况
- 是否有具体的自杀计划

**求助者可以主动告诉咨询师的**：
- 您的真实感受（即使觉得难以启齿）
- 任何让您感到痛苦的事情
- 您已经尝试过的应对方法
- 您需要的具体帮助
- 您的顾虑和担忧

## 热线咨询的局限性

### 热线无法替代的情况

| 情况 | 建议 |
|-----|------|
| 急性精神症状（幻觉、妄想） | 立即就医（精神科急诊或综合医院精神科） |
| 严重躯体疾病伴随心理危机 | 拨打120急救 |
| 物质中毒（药物/酒精） | 立即拨打120急救 |
| 需要住院治疗 | 联系精神科门诊或急诊 |
| 持续的日常心理咨询需求 | 建议寻求面对面心理咨询服务 |

### 热线咨询的优势

- **即时性**：24小时可用，危机时刻可立即联系
- **便捷性**：无需预约，无需出门
- **匿名性**：可匿名求助，降低求助门槛
- **专业性**：咨询员经过专业培训

## 热线与医疗系统的衔接

### 转介标准

热线咨询师在以下情况下会将来电者转介至医疗系统：

- 自杀风险评估为**高危**
- 需要**住院治疗**的精神障碍
- 存在**共病**（物质滥用、精神病性症状）
- 来电者**主动要求**转介
- 热线咨询**效果有限**，需要更深入治疗

### 转介流程

```
热线评估为高风险
    ↓
咨询师向来电者说明转介必要性
    ↓
联系就近的精神卫生机构或急诊
    ↓
提供具体就诊信息和预约方式
    ↓
确认来电者是否接受转介
    ↓
如来电者拒绝：
  - 继续热线支持
  - 指导联系家属陪同就医
  - 记录并安排后续跟进电话
```
