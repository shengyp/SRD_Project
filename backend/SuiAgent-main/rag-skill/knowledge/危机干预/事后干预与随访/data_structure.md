# 事后干预与随访

## 用途
自杀危机事后干预与随访指南，包括危机后心理支持、随访时间线（24-48小时、1周、2周、1/3/6个月）、风险追踪、团队协作及长期康复支持。WHO数据显示及时随访可将重复自伤风险降低50%。

## 权威来源
WHO mhGAP（2019）；Zero Suicides Initiative；Postvention最佳实践指南

## 文档描述
本文档系统介绍自杀危机事后干预与随访方案：1）随访时间线框架（出院后24-48小时首次随访，1周、2周、1/3/6个月定期随访）；2）每次随访必做内容（安全评估、症状监测、治疗方案调整）；3）风险等级与随访频率决策；4）社会支持激活（家属教育、同伴支持）；5）特殊人群干预（青少年、物质滥用共病者）；6）长期康复里程碑与复发预防。本文裨对VIS4SRD系统的价值在于指导随访管理模块和智能提醒功能。
