# 事后干预与随访

> 本文档介绍自杀危机事后干预与随访的最佳实践，包括危机后心理支持、随访计划和长期康复。来源：WHO mhGAP、Postvention指南、循证随访研究。

---

## 事后干预概述

### 定义

事后干预（Aftercare / Postvention）是指在自杀未遂事件发生后，对个体进行的后续心理支持、风险管理和康复计划。**自杀未遂是未来自杀最强预测因子之一**，规范的事后干预至关重要。

### 关键数据

- 有过自杀未遂者，未来自杀风险是无未遂史者的 **6-8 倍**
- **约 25%** 的自杀死亡者在死前30天内有急诊就诊史
- 及时的随访可将重复自伤风险降低 **50%**

## 随访框架

### 时间线

| 时间点 | 干预内容 |
|-------|---------|
| **出院后 24-48小时** | 首次主动随访（电话/面谈） |
| **出院后 1周** | 第2次随访，评估安全计划执行情况 |
| **出院后 2周** | 第3次随访，调整支持策略 |
| **出院后 1个月** | 正式门诊随访，评估治疗方案 |
| **出院后 3个月** | 评估康复进展，调整随访频率 |
| **出院后 6-12个月** | 持续监测，进入常规随访 |

### 随访频率决策

| 风险等级 | 建议随访频率 |
|---------|------------|
| **极高危** | 出院后每周1-2次×4周，然后每2周×8周 |
| **高危** | 出院后每周1次×8周，然后每月×6个月 |
| **中危** | 每2周1次×3个月，然后每月×6个月 |
| **低危** | 每月1次×6个月，然后根据需要 |

## 事后干预内容

### 1. 安全评估（每次随访必做）

**C-SSRS 快速评估**：

1. "自上次见面以来，您是否有过不想活或结束生命的想法？"
2. "您是否有过具体的自杀计划？"
3. "您是否有过自杀的尝试？"

**环境安全确认**：
- 高危物品是否已移除/锁定？
- 药物是否由家属保管？
- 环境是否安全？

### 2. 症状监测

| 症状域 | 评估内容 |
|-------|---------|
| **抑郁症状** | 情绪、兴趣、睡眠、食欲 |
| **焦虑症状** | 担忧、紧张、躯体焦虑 |
| **自杀意念** | 频率、强度、持续时间、是否可控 |
| **功能状态** | 工作、社交、日常生活 |
| **治疗依从性** | 是否按医嘱服药/接受心理治疗 |

### 3. 治疗方案调整

| 情况 | 调整建议 |
|-----|---------|
| 症状改善 | 维持当前方案，逐步减少随访频率 |
| 症状稳定但有残留 | 继续当前方案，考虑加强心理治疗 |
| 症状恶化或反复 | 升级治疗（加药/换药/住院评估） |
| 出现新的风险因素 | 重新评估风险等级，缩短随访间隔 |

### 4. 社会支持激活

**支持网络评估**：
- 家属/朋友是否知情并愿意参与？
- 是否存在有效的支持者？
- 支持者是否了解如何提供帮助？

**支持者教育**：
- 了解自杀风险信号
- 知道如何联系紧急服务
- 理解患者需要而非过度保护
- 照顾好自己的身心健康

## 特殊人群的事后干预

### 青少年自杀未遂后

**家长/监护人参与**：
- 家长心理教育（减少指责，增加理解）
- 家庭沟通技巧培训
- 家庭安全环境管理
- 与学校协调（返校安排、特殊照顾）

**同伴支持**：
- 评估同伴是否是风险因素（如欺凌）
- 激活支持性同伴关系
- 必要时调整社交环境

### 有物质滥用共病者

**双重治疗**：
- 同时治疗物质使用障碍
- 评估物质使用是否是触发因素
- 提供物质滥用专科资源
- 制定物质使用应急预案

### 有精神病性症状者

**精神科联合管理**：
- 密切监测精神病性症状
- 确保抗精神病药物依从性
- 评估洞察力水平
- 必要时考虑长效针剂

## 长期康复支持

### 康复的里程碑

| 时间 | 里程碑 |
|-----|-------|
| **1个月** | 安全计划内化、开始规律治疗 |
| **3个月** | 危机稳定、建立治疗关系 |
| **6个月** | 功能恢复、日常活动回归 |
| **1年** | 维持稳定、复发预防 |
| **2年+** | 长期康复、价值导向生活 |

### 预防复发的策略

1. **识别早期预警信号**：教会个体识别自己的预警信号
2. **应对技能强化**：定期复习安全计划和应对策略
3. **持续治疗**：维持药物治疗和/或心理治疗
4. **生活规律**：保持规律睡眠、运动、社交
5. **意义建构**：帮助重建生活目标和价值
6. **希望培育**：强调进步和康复的可能性

### "危机后成长"（Post-Traumatic Growth）

研究表明，部分经历过自杀危机的人可以实现积极的心理成长：

- 更珍惜生命和人际关系
- 发现新的生活意义
- 更强的心理韧性和自我效能
- 更深刻的人生价值观
- 更丰富的共情和亲密能力

## 干预者的后续跟进

### 定期沟通

- 每次随访后更新风险评估记录
- 及时与团队分享风险变化
- 记录安全计划调整内容
- 追踪转介执行情况

### 团队协作

| 角色 | 职责 |
|-----|------|
| **精神科医生** | 药物治疗管理 |
| **心理咨询师** | 心理治疗、安全计划跟进 |
| **个案管理员** | 协调随访、资源链接 |
| **家属/支持者** | 日常监护、安全环境 |
| **全科医生** | 躯体健康、共病管理 |
