# 危机干预主题索引

## 用途
危机干预是自杀预防的关键环节。本主题涵盖：1）热线与即时求助（12356全国统一心理援助热线、各省市热线）；2）现场干预要点（心理急救、安全评估、安全计划）；3）事后干预与随访（随访时间线、风险追踪）。本主题为VIS4SRD系统提供危机状态下的即时资源推荐和干预指导。

## 主题基本信息
- **主题名称**：危机干预
- **主题代码**：crisis_intervention
- **主题描述**：危机干预热线与现场处理相关内容
- **所属分类**：国家卫生健康委员会心理援助热线指南（2024）
- **权威来源**：国家卫生健康委员会、WHO mhGAP

## 文档描述
本主题包含4个核心文档：1）心理援助热线与即时求助指南（热线使用技巧、12356热线介绍）；2）全国心理危机热线.txt（全国各省心理援助热线号码）；3）现场危机干预要点（心理急救步骤、安全评估、安全计划）；4）事后干预与随访（随访时间线、风险追踪、团队协作）。关键词：危机、热线、12356、现场干预、安全计划、转介、随访、自杀危机。
