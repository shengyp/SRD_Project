# 现场危机干预要点

> 本文档介绍现场危机干预的操作要点，包括评估、干预和安全策略。来源：WHO mhGAP、循证危机干预研究、美国急诊精神医学学会（AAEP）指南。

---

## 现场危机干预概述

### 定义

现场危机干预（On-site Crisis Intervention）是指在危机发生的现场（如急诊室、社区、家庭等），由专业人员对处于急性心理危机的个体实施的即时干预措施。

### 适用范围

| 场景 | 说明 |
|-----|------|
| 急诊室 | 自杀未遂/自伤后送医患者 |
| 精神科急诊 | 急性精神病性症状伴危机 |
| 社区现场 | 自杀企图现场干预 |
| 学校/单位 | 群体危机事件（如自杀群发） |
| 电话/网络 | 热线远程危机干预 |

## 危机评估框架

### C-SSRS 现场评估维度

| 维度 | 评估内容 | 重要性 |
|-----|---------|-------|
| **自杀意念** | 有无死亡/自杀想法 | 核心 |
| **计划** | 时间、地点、方式的明确性 | 高 |
| **意向** | 采取行动的意图强度 | 高 |
| **行为** | 准备行为或未遂 | 极高 |
| **既往史** | 自杀未遂次数和严重程度 | 高 |
| **保护因素** | 社会支持、可利用资源 | 缓冲 |

### 现场风险分级

| 风险等级 | 指标 | 建议 |
|---------|------|------|
| **极高危** | 有计划+有手段+有历史+目前活跃 | 立即住院（保护性约束如必要） |
| **高危** | 有计划 OR 有近期未遂 | 住院或密集监护（1:1护理） |
| **中危** | 反复有意念但无计划 | 门诊+安全计划+家属陪伴 |
| **低危** | 偶有意念但可控 | 常规随访+心理教育 |

## 现场干预步骤

### STEP 1：建立安全环境

**目标**：确保干预者和被干预者的安全

**操作要点**：
- 移除现场所有可用的高危物品（药物、刀具、绳索等）
- 选择安静、私密但可监控的空间
- 确保门可以打开（不反锁）
- 如有必要，安排人员在外守候
- 避免过多人员在场（增加压力）

### STEP 2：建立连接与沟通

**原则**：非评判性、同理心、真诚

**沟通技巧**：

| 技巧 | 操作方法 |
|-----|---------|
| **开放式提问** | "能告诉我发生了什么吗？"而非"你是不是想死？" |
| **反映情感** | "听起来你非常痛苦/绝望" |
| **验证体验** | "在这种情况下感到绝望是很自然的反应" |
| **避免评判** | 不说"你怎么能这样想"、"你应该..." |
| **保持冷静** | 语音语调平稳，避免惊慌或过度紧张 |

**禁忌行为**：
- ❌ 告诉对方"你不能死"或"你不能做傻事"
- ❌ 说"你已经很幸运了，比你惨的人多了"
- ❌ 争论宗教/道德观点
- ❌ 承诺无法做到的事情
- ❌ 让危机个体独处（除非安全计划已制定）

### STEP 3：评估风险

**使用 C-SSRS 框架进行标准化评估**：

1. "您是否希望自己已经死了，或者希望可以睡着然后不再醒来？"
2. "您是否有过自杀的想法？"
3. "您是否有过自杀的计划？"
4. "您是否有过自杀的尝试？"

**关键问题**：
- "您计划怎么做？"
- "您打算什么时候做？"
- "您有办法实施这个计划吗？"
- "之前您是否有过类似的尝试？"
- "是什么让您今天联系我们/让您还活着？"

### STEP 4：制定安全计划

**目标**：将"活着"的具体策略书面化

**安全计划内容**：

```
第1部分：我的预警信号（早期信号）
- 内在信号：_______________
- 外在信号：_______________

第2部分：我可以采取的应对方式（不用伤害自己）
1. _______________
2. _______________
3. _______________

第3部分：我可以联系的人
- 家人/朋友：___ 电话：___
- 同事/邻居：___ 电话：___

第4部分：我可以联系的专业人员
- 主治医生：___ 电话：___
- 心理咨询师：___ 电话：___
- 心理热线：400-161-9995

第5部分：确保我的环境安全
- 需要移除/锁定的物品：_______________
- 需要拜托他人保管的东西：_______________

第6部分：我的承诺
"即使我感到非常痛苦，我承诺至少等待24小时再做出任何决定。
我会活下去，因为：_______________"
```

### STEP 5：资源链接与转介

**评估是否需要更高级别的护理**：

**需要住院的情况**：
- 目前正在实施或即将实施自杀
- 有具体计划+可及手段+近期未遂史
- 严重精神病性症状
- 拒绝进食/拒绝配合
- 无支持网络

**可门诊处理的情况**：
- 有意念但无具体计划
- 有社会支持
- 愿意配合安全计划
- 无精神病性症状

## 特殊场景的干预要点

### 自杀未遂后的现场干预

| 阶段 | 干预重点 |
|-----|---------|
| **急性期（0-24h）** | 确保安全、评估风险、制定安全计划 |
| **住院期间** | 持续评估、安全管理、开始心理评估 |
| **出院前** | 安全计划确认、随访安排、资源链接 |
| **出院后（1周内）** | 主动随访、评估调整、支持网络激活 |

### 物质相关危机的现场干预

**关键步骤**：
1. 确保躯体安全（急救、催吐、洗胃等医疗处理）
2. 评估精神状态（清醒程度、中毒程度）
3. 评估自杀风险（意图判断：意外 vs 故意）
4. 如为故意过量 → 纳入标准危机干预流程

### 青少年自杀危机的现场干预

**特殊考量**：
- 父母/监护人的参与（但需尊重青少年隐私）
- 学校资源的链接
- 同伴支持网络的激活
- 青少年特有的风险因素（欺凌、学业压力等）

## 干预者的自我保护

### 二次创伤的风险

从事危机干预的人员可能经历：
- 共情疲劳（Compassion Fatigue）
- 替代性创伤（Vicarious Trauma）
- 职业倦怠（Burnout）

### 自我保护策略

| 策略 | 说明 |
|-----|------|
| **同事支持** | 定期与同事讨论困难案例 |
| **督导** | 定期接受专业督导 |
| **情绪释放** | 工作后有安全的情绪处理渠道 |
| **边界** | 清楚的工作时间和休息时间 |
| **自我关怀** | 保持健康的生活方式 |
| **案例交接** | 不要长期单独负责高危案例 |
