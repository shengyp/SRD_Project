# 现场干预要点

## 用途
现场危机干预操作指南，包括心理急救（PFA）步骤、危机评估方法、安全计划制定及转介要点。适用于医护人员在急诊室、社区或学校等场景下对自杀危机个体的即时干预。

WHO mhGAP；国家卫生健康委员会心理危机干预指南；心理急救（PFA）国际认证课程

## 文档描述
本文档系统介绍现场危机干预的操作要点：1）心理急救（PFA）六步法（观察、倾听、联系、协助、过渡、保障安全）；2）危机评估要素（自杀意念强度、计划具体性、手段可及性、既往史）；3）安全计划制定（五要素：识别预警信号、列出应对策略、记录可求助人员、记录安全环境设置、列出专业求助渠道）；4）转介流程与注意事项。本文裨对VIS4SRD系统的价值在于为危机状态下的即时干预提供规范化指导。
