# 焦虑应对策略

## 用途
循证焦虑应对方法与技能训练，包括：认知重构、正念减压、放松训练（腹式呼吸、渐进性肌肉放松）、暴露疗法及DBT情绪调节技能。焦虑应对技能是自杀风险干预的重要组成部分。

## 权威来源
CBT循证研究；DBT官方指南（Linehan）；正念减压（MBSR）循证研究

## 文档描述
本文档系统介绍循证焦虑应对方法：1）认知重构技术（识别焦虑思维、挑战灾难化思维）；2）正念减压（MBSR：呼吸觉察、身体扫描）；3）放松训练（腹式呼吸、渐进性肌肉放松）；4）暴露疗法（分级暴露、反应预防）；5）DBT情绪调节技能（识别情绪、核查事实）。本文裨对VIS4SRD系统的价值在于提供焦虑自助技能指导和RAG对话干预建议。
