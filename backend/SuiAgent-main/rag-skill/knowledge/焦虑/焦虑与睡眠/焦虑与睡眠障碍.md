# 焦虑与睡眠障碍

> 本文档介绍焦虑与睡眠障碍的相互关系及其临床意义。来源：DSM-5、美国睡眠医学会（AASM）指南、循证研究。

---

## 焦虑与睡眠的相互关系

焦虑和睡眠障碍之间存在**双向关系**：焦虑可导致睡眠问题，而睡眠不足又会加重焦虑症状，形成恶性循环。

### 流行病学

- 约 **50-70%** 的焦虑障碍患者存在失眠问题
- 失眠患者发生焦虑障碍的风险是正常人的 **2-3倍**
- 社交焦虑障碍患者的失眠共病率约 **40-50%**
- PTSD 患者的梦魇和睡眠片段化问题尤为突出

---

## 焦虑影响睡眠的机制

### 1. 生理机制

| 机制 | 说明 |
|-----|------|
| **交感神经激活** | 焦虑激活应激反应，导致心率加快、血压升高，难以入睡 |
| **皮质醇升高** | 焦虑导致HPA轴激活，夜间皮质醇水平升高 |
| **警觉性增加** | "战斗或逃跑"系统持续激活，大脑无法进入放松状态 |
| **肌肉紧张** | 躯体焦虑症状（肌肉僵硬、颤抖）影响睡眠舒适度 |

### 2. 心理机制

| 机制 | 说明 |
|-----|------|
| **反刍思维** | 反复思考担忧内容，导致难以入睡 |
| **睡眠恐惧** | "担心睡不着"的焦虑本身导致失眠（失眠焦虑螺旋） |
| **预期性焦虑** | 对第二天焦虑事件的提前担忧 |
| **负性认知** | 对睡眠问题灾难化（"睡不着明天就完了"） |

## 焦虑相关的睡眠障碍类型

### 1. 失眠（Insomnia）

**最常见的共病类型**，表现为：
- **入睡困难**：躺在床上超过30分钟仍无法入睡
- **睡眠维持困难**：夜间频繁醒来，难以再次入睡
- **早醒**：比预期提前醒来，无法再次入睡
- **日间功能障碍**：疲劳、注意力不集中、情绪波动

### 2. 睡眠片段化（Sleep Fragmentation）

- 夜间多次醒来，睡眠结构被打断
- 深度睡眠（N3）和REM睡眠比例减少
- 第2天感觉"睡不沉"

### 3. 噩梦与梦魇障碍

- **噩梦**：强烈恐惧或焦虑相关的梦，通常在REM睡眠期
- **梦魇障碍**：频繁噩梦导致睡眠紊乱和日间功能障碍
- PTSD患者的梦魇尤为严重

### 4. 睡眠呼吸暂停的共病

- 阻塞性睡眠呼吸暂停（OSA）患者焦虑水平较高
- OSA的治疗改善可同时减轻焦虑症状
- 需注意鉴别：以打鼾、夜间呼吸暂停为主诉

## 临床表现

### 焦虑性失眠的特征

| 特征 | 具体表现 |
|-----|---------|
| **入睡前活跃** | 躺下后大脑反而更清醒，思绪纷乱 |
| **担忧驱动的觉醒** | 因担忧特定事件而无法入睡 |
| **夜间觉醒** | 凌晨醒来后难以再次入睡，大脑自动进入担忧模式 |
| **早醒** | 清晨（通常4-5点）醒来，无法再睡 |
| **日间疲惫** | 尽管卧床时间足够，仍感疲劳 |

### 鉴别要点

| 疾病 | 睡眠问题特点 | 其他特征 |
|-----|------------|---------|
| **GAD伴失眠** | 入睡困难+夜间觉醒 | 持续担忧，躯体焦虑症状 |
| **惊恐障碍伴失眠** | 入睡困难+噩梦 | 夜间惊恐发作 |
| **PTSD伴失眠** | 睡眠片段化+噩梦 | 闪回、过度警觉 |
| **抑郁症伴失眠** | 早醒（典型） | 快感缺失、兴趣减退 |
| **原发性失眠** | 主观失眠（睡眠感知障碍） | 无显著焦虑症状 |

## 治疗策略

### 1. 认知行为治疗-失眠（CBT-I）

**CBT-I 是失眠的循证一线治疗**，对焦虑伴失眠患者同样有效：

**睡眠限制疗法**：
- 限制卧床时间为实际睡眠时间
- 建立固定的起床时间
- 避免白天补觉

**刺激控制疗法**：
- 床仅用于睡眠和亲密行为
- 入睡困难时离开床，进行放松活动
- 保持规律的睡眠-觉醒周期

**认知疗法**：
- 识别和挑战关于睡眠的负性认知
- 减少对失眠的灾难化思维
- 建立"床=睡眠"的正向联结

### 2. 焦虑专项治疗

**药物治疗**：

| 药物类型 | 示例 | 对睡眠的影响 | 注意事项 |
|---------|------|------------|---------|
| **SSRIs** | 帕罗西汀、艾司西酞普兰 | 初期可能加重失眠 | 早晨服用 |
| **SNRIs** | 文拉法辛 | 初期可能加重失眠 | 早晨服用 |
| **苯二氮卓类** | 阿普唑仑、氯硝西泮 | 改善睡眠，减少夜间焦虑 | 短期使用（≤4周），依赖风险 |
| **非苯二氮卓类** | 唑吡坦、右佐匹克隆 | 改善入睡 | 短期使用 |
| **米氮平** | 米氮平 | **改善睡眠**，增加睡眠效率 | 睡前服用，抗抑郁+改善睡眠 |

**心理治疗**：
- 认知行为疗法（CBT）治疗焦虑
- 正念减压（MBSR）
- 放松训练（渐进性肌肉放松、呼吸训练）

### 3. 联合干预

**推荐的联合方案**：
```
急性期（0-12周）：
├── CBT-I（认知行为治疗失眠）
├── SSRIs/SNRIs（改善焦虑基础症状）
└── 短期使用苯二氮卓类或非苯二氮卓类（≤4周）

维持期（12周+）：
├── 继续CBT-I技能
├── SSRIs/SNRIs维持治疗
└── 定期评估和调整
```

## 生活方式建议

### 睡眠卫生（Sleep Hygiene）

- **规律作息**：固定时间睡觉和起床（包括周末）
- **卧室环境**：安静、黑暗、凉爽（约18-20°C）
- **避免刺激物**：睡前6小时避免咖啡因，睡前2小时避免酒精
- **限制屏幕**：睡前1小时不使用电子设备
- **规律运动**：但避免睡前3小时剧烈运动

### 放松技术

- **渐进性肌肉放松**：从脚到头逐组肌肉收紧后放松
- **深呼吸**：4-7-8呼吸法（吸气4秒，屏气7秒，呼气8秒）
- **正念冥想**：关注呼吸，接受当下
- **想象放松**：想象宁静的场景（海滩、森林等）
