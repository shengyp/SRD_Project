# 焦虑与睡眠

## 用途
焦虑对睡眠的影响及相关障碍，包括：焦虑-失眠恶性循环、HPA轴激活机制、焦虑共病失眠的风险评估（失眠使自杀风险增加2倍）。改善睡眠是焦虑干预的重要组成部分。

## 文件说明
- 焦虑与睡眠障碍.md - 焦虑与睡眠障碍关系完整指南

## 关键词
焦虑与睡眠、失眠、心率加快、呼吸急促、睡眠障碍、焦虑失眠共病、HPA轴、觉醒过度

## 权威来源
AASM睡眠障碍分类；焦虑障碍研究；失眠-抑郁-自杀三元模型

## 文档描述
本文档分析焦虑与睡眠障碍的关系：1）焦虑导致失眠的机制（过度觉醒、HPA轴激活）；2）失眠加剧焦虑的机制（睡眠剥夺增加皮质醇）；3）焦虑-失眠-抑郁三元模型；4）失眠对自杀风险的影响（风险增加2倍）；5）改善睡眠的循证策略（CBT-I、睡眠卫生教育）。本文裨对VIS4SRD系统的价值在于识别焦虑-睡眠共病风险和提供综合干预建议。
