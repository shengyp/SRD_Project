# 广泛性焦虑与识别

## 用途
广泛性焦虑障碍(GAD)识别与GAD-7量表评估，包括GAD定义（持续6个月以上的过度担忧）、诊断标准、与抑郁症的共病关系及GAD-7评分标准（5/10/15分为轻/中/重度焦虑）。

## 文件说明
- 广泛性焦虑障碍识别与GAD-7评估.md - GAD定义与GAD-7评估方法完整指南

## 关键词
GAD-7、广泛性焦虑、惊恐障碍、社交焦虑、紧张、担忧、过度担忧、共病、评分标准

## 权威来源
GAD-7官方评分标准 (Spitzer et al., 2006)；DSM-5；ICD-11

## 文档描述
本文档系统介绍广泛性焦虑障碍：1）GAD定义与诊断标准（DSM-5：6个月以上过度担忧）；2）GAD-7量表详解（7题，5/10/15分为临界/中度/重度）；3）GAD与抑郁共病（GAD患者中50%共病抑郁）；4）焦虑自杀风险（焦虑患者自杀风险是普通人群2-3倍）；5）鉴别诊断（惊恐障碍、社交焦虑障碍）。本文裨对VIS4SRD系统的价值在于指导GAD-7量表解读和焦虑风险评估。
