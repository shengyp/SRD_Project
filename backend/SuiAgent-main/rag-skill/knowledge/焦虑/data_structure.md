# 焦虑主题索引

## 用途
焦虑是自杀的重要风险因素之一，约30%的焦虑障碍患者一生中会有自杀想法。本主题涵盖：1）广泛性焦虑障碍识别与GAD-7评估；2）焦虑与睡眠障碍关系；3）循证焦虑应对策略。本主题为VIS4SRD系统的焦虑风险筛查提供支持。

## 主题基本信息
- **主题名称**：焦虑
- **主题代码**：anxiety
- **主题描述**：焦虑障碍相关内容、GAD-7评估与应对
- **所属分类**：GAD-7官方指南
- **权威来源**：Spitzer, Kroenke, Williams & Löwe (2006); GAD-7官方评分标准

## 文档描述
本主题包含4个核心文档：广泛性焦虑障碍识别与GAD-7评估（GAD定义、诊断标准、GAD-7使用）；焦虑与睡眠障碍（焦虑对睡眠的影响机制）；焦虑应对策略（循证方法）。关键词：焦虑、GAD-7、惊恐障碍、社交焦虑、正念、CBT、放松训练。

## 子主题列表

- 应对策略：循证焦虑应对方法
