# 心理学量表 CSV 包说明

本压缩包包含：
1. scale_meta.csv：量表基本信息
2. scale_questions_all.csv：全部量表题目配置
3. scale_options_all.csv：选项与分值配置
4. scale_scoring_rules_all.csv：评分规则与风险等级
5. github_references.csv：可参考的 GitHub 仓库
6. 每个量表单独的 questions/scoring_rules 文件

重要说明：
- 题干为“中文原型改写版”，便于课程项目、系统原型和演示部署。
- 正式用于医院服务前，请核对量表版权、授权中文版、伦理审批和临床适用范围。
- 量表结果应标注为“辅助筛查，不替代专业诊断”。
- PHQ-9 第9题、SDS 第19题等涉及死亡/自伤意念，非零或高分时建议触发人工复核与危机干预流程。
